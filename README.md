# CineWeave · 造梦工坊（v1.28.0）

一个本地优先的 AI 视频创作工作台：为**已有剧本/分镜**的创作者提供画布、镜头表、资产管理、3D 白模预演、图片/视频生成与粗剪，全部在同一个工程里完成。

产品边界：不生成剧本、大纲或对白，不做创作助手对话，不做 AI 自动分镜/资产设计；只服务已写好剧本的预演与生成。

## 功能

- **六阶段导航**：剧本 / 镜头 / 资产 / 预演 / 生成 / 剪辑，切换工作重点不丢画布状态
- **剧本参考 + 手工镜头表**：粘贴已有剧本作为只读参考；逐镜维护场景、画面、时长、运镜与对白
- **资产管理**：角色 / 场景 / 道具、参考图、正式图与版本；离线模型库
- **画布**：节点、连线、分组、对齐、框选、复制粘贴、小地图与快捷键
- **3D 导演台**：three.js 实时舞台、机位/走位/动作/关键帧、贝塞尔路径、机位监看；按镜头导出白模参考视频包（自动规范为 24fps）
- **即梦式画布**：点阵画布、左竖创建栏、节点外部类型标签、底部小生成卡（840px / ≤40vh）、顶部小面包屑
- **多素材参考**：视频节点可连接多张图片、多段视频、多段音频，按连线顺序生成 `<Picture n>`/`<Video n>`/`<Audio n>` 参考，保存引用快照
- **统一生成面板**：图片/视频共用一个底部面板；参考、模型、画幅/分辨率、时长；费用确认后只保留一个主操作
- **生成历史**：列出排队 / 生成中 / 已完成 / 失败任务，可刷新状态、完成后加入画布；关闭面板或停止等待后进行中任务仍可找回，不重复创建节点
- **Seedance 2.5（可选）**：配置后可选用多素材 Provider（30/10/10/50、4–30s、480p/720p/1080p）；未配置时禁用，不把 1.0 伪装成 2.5
- **剪辑**：粗剪时间轴、素材库、版本对比、按镜头导出
- **项目管理**：多项目独立保存、缩略图、搜索排序、复制重命名、导入导出、回收站
- **本地优先**：只监听 `127.0.0.1`，工程与素材保存在本机，不依赖外网

## 安装（Apple Silicon）

发布产物：`造梦工坊-v1.28.0-AppleSilicon.dmg`（macOS arm64，macOS 13+）。

1. 打开 DMG，将「造梦工坊.app」拖入 Applications（应用程序）文件夹；
2. 首次打开如提示“无法验证开发者”，在“系统设置 → 隐私与安全性”中仍要打开；
3. 本包为本机临时签名，未做 Apple Developer ID 签名与公证，请只从可信来源获取安装包。

工程数据保存在 `~/Library/Application Support/AIWorkstation`，升级/重装不会删除；重要工程请从“项目库 → 导出”备份 JSON。详细步骤与 DMG 校验值见 [v1.28.0 验收记录](docs/RELEASE-ACCEPTANCE-1.28.0.md)，随包使用说明见 `desktop/安装与使用说明.txt`。

H3 只保留本地接口与缺失项检测，**不自动下载、不安装模型**；未安装 H3 不影响现有生成流程。Seedance 2.5 多素材参考需在方舟配置 API Key 并显式开启；本地视频/音频参考 URL 托管尚未打通，会在生成前明确提示。

## 本地开发

要求：Node.js 20+，macOS（打包脚本以 macOS 为主）。

```bash
npm ci
npm run dev        # Vite 开发服务 http://127.0.0.1:5173
npm start          # 构建后的本地服务 http://127.0.0.1:4173
npm test           # Node 测试
npm run build      # 生产构建
```

桌面版开发 / 打包：

```bash
npm run package:mac
npm run package:dmg
```

`package:mac` 需要 Electron 缓存；可使用 `ELECTRON_ZIP_DIR=<electron zip 缓存目录>` 指定离线包。

## 首次使用

1. **项目库**：新建项目或导入已有工程 JSON。
2. **设置 → API 服务**（可选）：配置本地 ComfyUI（免费）或 Seedream 等云端服务；未配置云端服务时仍可使用画布、镜头表、3D 白模、本地 ComfyUI 与剪辑。
3. **剧本**：粘贴/导入已有剧本参考（只作参考，不生成剧本）。
4. **镜头**：手工维护镜头表并保存。
5. **资产**：建立角色/场景/道具，导入或生成参考图，选择正式图。
6. **预演**：在 3D 导演台完成机位、走位、动作与关键帧，按镜头导出白模参考视频包。
7. **生成**：选中节点或进入“生成”阶段，在统一面板中查看费用并提交；结果可设为正式图 / 加入资产版本 / 送入剪辑。
8. **剪辑**：粗剪、替换片段、导出预演。

生成中可「停止等待」或按 Esc 关闭面板；任务在后台继续，之后在生成面板「最近生成」中刷新并找回结果。失败或停止后会重新获取报价，不复用失效报价。

### 键盘

- `⌘/Ctrl + Enter`：生成面板提交；剧本参考、镜头表保存
- `Esc`：关闭弹窗 / 取消；空闲时关闭生成面板
- `⌘S` 保存 · `V` 选择工具 · `H` 抓手 · `F` 适应画布 · `Delete` 删除所选
- 画布工具栏「快捷键」可搜索完整列表

## 离线资产（不随仓库提供）

为了控制仓库体积，`public/assets/models/` 和 `public/assets/thumbnails/` 未上传。完整使用离线模型库需要：

1. 从 Release 页下载资产包（`assets-cc0.zip`）；
2. 解压到 `public/assets/`，保持 `models/` 与 `thumbnails/` 目录结构；
3. 重新 `npm run build`。

资产清单、来源与许可证见 [ASSETS.md](ASSETS.md)。即使没有资产包，画布、剪辑和大部分界面功能仍可运行。
