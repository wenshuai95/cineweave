一、逐项实现情况（对照开发意见 1–8）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【1 选择工具与抓手】已实现
- 新增独立工具状态：V 选择（默认）/ H 抓手；画布顶部浮动工具条含两个工具按钮（含 tooltip 快捷键），键盘 V / H 切换（仅画布模式、非编辑焦点、无弹窗/菜单时触发）。
- 选择工具空白拖拽 = 框选（.board-marquee 视觉矩形，世界坐标按当前 zoom 换算，节点用实际渲染高度缓存 nodeHeights 判交，部分压到即选中）；Shift / ⌘(Ctrl) + 点击节点 = 加选 / 减选；框选按住 Shift = 在原选择上追加。
- Space 按住 = 临时抓手（key repeat 幂等）；松开 keyup、窗口 blur、页面隐藏、焦点进入输入/媒体控件、打开任何 modal、切换模式（setMode）都会释放，不粘住。焦点在按钮/连线等可交互元素上时不劫持其 Space 激活。
- 中键拖拽平移（任何工具、任何位置，媒体控件与工具条除外，preventDefault 阻止浏览器自动滚动）；H 工具左键平移（含节点上方，媒体控件/连接端口 button/video/audio/input 优先放行，installPortDrag 原逻辑不动）。
- V 工具下拖动所选任一节点 = 批量移动全部所选（一次 checkpoint，整批一次撤销）；拖拽支持 pointercancel / lostpointercapture / 窗口 blur / Esc 取消：位置复原、撤销栈弹出本次 checkpoint（不留历史）、不留拖动状态（boardGesture 门闩在拖拽期间拦截其余快捷键，Esc 取消）。
- 普通（无 Shift）滚轮仍为缩放（原习惯保留）；新增 Shift+滚轮水平平移。旧"空白左键拖拽平移"被框选替代，平移改为 H / Space / 中键（按 brief 要求）。

【2 画布工具条】已实现
- 画布顶部浮动工具条：工具切换（V/H）、选中数量（aria-live 实时播报）、编组、解组、对齐 ▾ 菜单、复制、粘贴、删除、小地图开关、快捷键速查入口；全部按钮 tooltip 注明快捷键与语义。
- 批量移动 = 拖拽 / 方向键；批量删除按钮 + Delete / Backspace。删除只删所选画布节点与两端触及的画布连线，并自动清理空组；绝不触碰导演台对象 / 镜头 / 动作（deleteBoardSelection 不读写 p.objects / p.shots）。

【3 批量快捷键】已实现
- ⌘/Ctrl+A：选中当前分类下全部可见节点（nodeVisible(filter)）；Esc：清空选择（顺位在关闭弹窗/菜单/取消拖拽之后）；⌘/Ctrl+D：批量复制（失败原子，见 4）；Delete/Backspace：批量删除。
- 方向键 1 画布单位、Shift+方向键 10 单位；连续按键 1.2 秒内合并为一次撤销（nudgeStamp 合并窗口，任何其它 checkpoint 即打断窗口）。
- 触发保护沿用既有守卫：文字/表单焦点（editingTarget 含 video/audio）、模态、右键菜单打开、面板分隔条焦点、导出/切工程中一律不触发；拖拽进行中（boardGesture / timelineGesture）除 Esc 外全部拦截。舞台模式键盘（0-3 工具、WASD/QE/IJKL、Space 播放、G 落地、方向键移对象、Alt 滚轮、-/= 视野）原样保留，画布分支在舞台分支之前独立 return。

【4 画布剪贴板】已实现
- ⌘/Ctrl+C / ⌘/Ctrl+V 走 document copy/paste 事件 + 自有标记 MIME（application/x-director-canvas-nodes）；只在存在画布数据时 preventDefault，绝不吞系统复制/粘贴：paste 事件先读自有 MIME，缺失时若系统剪贴板有 text/plain 内容则直接放行，不窃读系统剪贴板内容（只在事件内探测自有标记与是否存在其它内容）。
- 同时保留会话内存剪贴（跨工程粘贴：openManagedProject 不清除 canvasClipboard，工程切换后 ⌘V 或工具条「粘贴」仍可放置副本，粘贴自动解除工程绑定）。
- 复制内容只走白名单字段：type/title/text/x/y/w/src/modelSrc/modelSize/modelKind——objectId、sceneObjectIds、modelTask、generatedTask 等旧工程绑定与在运行任务引用全部剥离；本地已完成媒体（src data URL）与模型（modelSrc/modelSize/modelKind）保留。
- 粘贴重新编号（新 uid）、位移错开（连续粘贴按 40px 递增错开）、保留所选节点间的内部连线（端点重映射到新 ID）、整批一次 checkpoint；粘贴后自动切回"全部"分类并选中新批次。
- 校验拒绝（pasteCanvasCopy，写入前整体抛错，保证原子失败）：非自有标记 / 版本不符 / 非数组 / 空 nodes / 单批 >500 / 剩余容量不足（limit=500-现有数，先检查后写入）/ 异常 ID（含格式）/ 不支持的节点类型 / 无效节点位置或尺寸（非有限数值、w 越界 100–1000 整批拒绝）/ 无效连线端点与自环、重复连线去重 / 无效分组与跨组重复成员 / model 节点缺合法 modelSrc 或尺寸/用途非法 / offset 与 limit 本身非法；超长 title/text 截断到 100/20000。（以上较初稿更严：越界尺寸由"钳制"改为"整批拒绝"，另加连线/分组去重，与本仓 tests/v1210.test.mjs 的当前断言一致。）
- 500 上限原子性：批量复制同样先检查 500-现有数，不足整批拒绝（不 checkpoint 已先弹回）；新增测试覆盖"剩余容量不足整批失败，无部分写入"。
- 已有单节点复制（duplicateCanvasNode：属性面板「复制节点」、右键菜单）统一到同一安全副本路径：所有类型副本一律解除对象绑定（此前非 model 节点副本会共享 objectId，属有意的行为变更，toast 中说明）。

【5 编组】已实现
- ⌘/Ctrl+G 编组（≥2 节点）、⌘/Ctrl+Shift+G 解组（解组所选节点触及的全部组）。
- 组保存为工程可选字段 boardGroups:[{id,name,memberIds}]（schema jingchang/1 不变；旧工程无此字段照常打开/保存/导入）。validateProject 新增校验：可选、数组 ≤200、id 合法且唯一、name ≤100 字符、memberIds 必须是已有节点且跨组不重复——导入异常分组会被拒绝，不能绕过。
- 可视组边框（虚线圆角框 + 标题条，含成员数）；点击组标题或组体选中整组；拖动标题整组移动（组内外连线与成员归属不变）；双击标题或右键标题菜单重命名（默认名"分组 N"，≤50 字符）。
- 多组重编组：regroup 先把所选成员移出其它组、空组自动消失，再入新组——无悬空成员/重复 ID（含测试）。删除节点后 pruneGroups 清理悬空成员与空组。复制时触及 ≥2 所选成员的组生成新 ID 副本组（成员映射到副本节点）。组操作全部走 checkpoint/commit，undo/redo 正常（boardGroups 随 p 快照）。组只是画布组织，不触碰 3D 场景。先不做嵌套与折叠（按 brief）。

【6 视图导航】已实现
- F 适应全部（旧习惯保留，fitBoard 原函数不动）；Shift+1 适应全部；Shift+2 聚焦所选（按实际渲染高度计算包围盒）；Shift+0 回到 100%；⌘/Ctrl + 加/减（含小键盘）缩放——鼠标在画布内以鼠标为锚（boardPointer 跟踪），否则视口中心（复用 zoom() 锚点公式）。
- 滚轮缩放习惯保留；Shift+滚轮水平平移；中键平移（见 1）。
- 小地图：右下角 canvas（168×112），绘制可见节点矩形（选中金色）+ 当前视口框；内容边界 = 节点 ∪ 视口（含留白，minimapBounds 纯函数）；点击/拖动小地图把视口中心定位到对应世界坐标；工具条 ◫ 开关（aria-pressed）；≤1200px 窗口 CSS 隐藏以保证工具条可用（开关状态保留）。随 boardTransform rAF 节流刷新。
- 顶部画布控制条（缩放/适应）原样保留。视图操作（F/Shift+数字/⌘加减/小地图拖动/平移）均不修改选择状态。
- 搜索定位（侧栏点击/Enter）：保留 v1.2.9 行为=选中并居中该节点（即定位会替换多选为该节点）；搜索输入框本身受 editingTarget 保护，输入过程不清空多选。此为对"既有搜索定位不破坏多选状态"的保守解释（定位语义必须选中目标节点），已如实标注，如需"定位但保留多选"请明确后再改。

【7 对齐与分布】已实现
- 对齐菜单（工具条「⇹ 对齐 ▾」）：左/右/顶/底/水平中心/垂直中心，≥2 节点启用；水平/垂直等距分布，≥3 节点启用（不足时 toast）。
- 使用实际渲染尺寸（nodeHeights 缓存，renderBoard 每次重测；新节点默认 250 回退）；以选中包围盒为基准；只改 x/y，w 不变；全部一次 checkpoint，一次撤销。纯函数 alignSelection / distributeSelection 有独立测试（含不同宽高的右对齐/底对齐/中心、等距间隙精确断言、跨度不变）。
