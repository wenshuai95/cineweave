# 镜场 v0.6 使用说明

本地地址：http://127.0.0.1:4173/ 。已有页面刷新后即可使用；工程保存在同一浏览器的本机数据库中。

## Solo

左侧对象行 S 为独显。同类对象改为单选：A → B 会取消 A 的 Solo；再次点击 B 会恢复这类对象。模型与摄影机辅助图标分组计算，因此 Solo 摄影机不会隐藏被拍摄的场景。左栏「退出全部 Solo · 恢复显示」可清除所有组的独显。对象锁定不受影响；Solo 只用于编辑视图，不裁掉正式预览/导出的场景内容。

## XYZ 旋转

选中对象后按 2，红、绿、蓝旋转环对应 XYZ。角色、模型和道具右栏有三轴角度，每轴旁的 ◇ 可独立打帧，数值可左键拖动。旧工程的“朝向”保留为 Y 旋转。

摄影机也有 XYZ 旋转环。旋转后同步更新红色注视点及镜头滚转，保持注视距离；机位监看、截图与导出均包含滚转。右栏可单独记录镜头滚转，以及注视点 XYZ 关键帧。

## 离线资产与骨骼

顶部常驻「⬡ 离线资产」，导演台工具条也有入口。人物分类新增：

- 成人比例男演员 · 骨骼白模：建议高 1.8 米，65 骨骼。
- 成人比例女演员 · 骨骼白模：建议高 1.7 米，65 骨骼。

两者包含蒙皮权重和手指骨骼，来源 Quaternius Universal Base Characters Standard，CC0；是成人基础比例预演白模，不是照片级写实人物。没有内置动作，保持参考姿态。有骨骼不等于自动能播放其他模型的动画，需做匹配/重定向。当前软件支持整体走位旋转关键帧、已有模型原生动画播放，尚无骨骼逐关节编辑/动画重定向。

新角色排在资产库最前面；原 20 个模型保留。许可和下载来源见 public/assets/README.txt 与 licenses。

## API 设置

顶部「⚙ API 设置」打开表单，填写 API 基础地址、服务商提供的准确模型 ID、API Key，点击「应用 API 配置」。兼容 HTTPS Chat Completions 接口；模型支持 JSON 输出，解读图片还需支持图片输入。模型名称不按产品宣传名猜测，以服务商实际提供为准。

Key 仅存本次本地服务进程内存，重启服务后重新填写；不进工程 JSON、不进 ZIP、不回显。已有环境变量配置仍可使用。仅改变网址域名时，必须重新输入该服务商对应的 Key，避免把旧密钥发给另一个服务商。

旧版媒体 CLI 按本机已有官方 CLI 授权运行，界面显示配置状态。点击「旧版媒体 CLI 生成图片」后查询模型/积分，再自行确认生成。未因本次测试提交真实收费生成。

## 图文生成场景 → 导演台

1. 右键新建文本节点，写场景描述；新建图片节点并导入参考图。
2. 按住一个节点右侧圆点，拖到另一个节点左侧圆点，松开连接。反向从输入点拖向输出点也可；Esc 或在空白处松开取消；不重复添加同一连线。
3. 选中文本/图片节点，点右侧「生成场景 → 导演台」，或上方「图文 → 3D 场景」。读取所选节点和直接相连节点，最多 2 张 PNG/JPEG/WebP 图片。未选节点也可直接输入描述。
4. 选择本地规则或 DeepSeek 规划，点击「生成编排方案」先预览，再点「加入导演台」。软件添加模型，自动打开导演台，同时在画布增加一个预演节点；可整体撤销。
5. 选中添加的模型，设计位置、XYZ 旋转、比例、路径与关键帧。

本地规则只识别文字中的基础类别，不分析图片或精确理解数量/空间关系。云端规划需有效 API 与支持图片输入的模型；当前用户未提供 Key，因此尚未实测云端图文规划。

此流程生成的是“使用已有模型的可编辑场景布局”，不生成新的几何网格，也不等于精确重建参考图片。若要新房屋/新人物造型，先在 Meshy、Tripo 等专门建模服务生成并下载含内嵌纹理的 GLB，再点「离线资产 → 导入本地 GLB」。最大 40 MB；不支持外部资源、DRACO/KTX 解码依赖。图文建模平台 API 尚未直接集成。

多个画布预演节点共享同一工程三维场景，尚不是相互隔离的多个片场。
