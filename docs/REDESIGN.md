# 造梦工坊下一步：从“工具箱”重构成“流水线”

日期：2026-10-19　｜ 研究对象：v1.23.1 源码与界面　｜ 性质：设计研究，未改动现有界面

---

## 0. 一句话结论

你描述的工作流是**一条线性流水线**（灵感 → 剧本 → 分镜 → 资产 → 预演 → 生成 → 剪辑）；
现在的软件是**一个工具箱**（画布、导演台、助理、素材库、剪辑各自成岛）。
下一步不是加功能，而是**把工具箱重组为流水线**：画布降为“高级模式”，六段式主导航成为主界面。

---

## 1. 现状诊断（量化）

| 指标 | 现状 |
|---|---|
| 顶层页面 | 画布 / 3D 导演台（顶部 tab）+ 画布 / 剪辑（底部 nav） |
| 隐藏工具 | 创作助手 / 文稿与分镜 / 项目素材（从侧栏工具条打开） |
| 助手子页 | 对话 / 白模导演 / 文稿 / 设定（4 个并列） |
| 弹窗 | **33 个** Modal 函数 |
| 按钮 | **184 个**带 id 的按钮；单屏可见 20–30 个 |
| 同一能力多入口 | 助手 3 套、分镜 3 处、资产 3 处、视频输出 3 处 |
| 单文件 | `src/main.js` 2375 行，UI 与业务混在一起 |

### 具体错位

1. **流程在界面里不存在。** 你脑子里是“剧本→分镜→资产→生成”，界面里是“画布/导演台/剪辑”。用户必须先理解工具，才能理解流程。
2. **概念暴露了实现。** 节点、连线、版本、媒体库、fps、模型 ID、存储路径都出现在界面上；用户想的是“这场戏”“这个镜头”。
3. **同一个东西多个名字。** 创作助手 / 白模助手 / 白模导演；镜头清单 / 文稿与分镜 / 拍摄表；项目素材 / 离线资产 / 资产库。
4. **3D 导演台是编辑器，不是助手。** 每个对象都要手摆，机位要手调；白模导演只做局部修补，无法从“一句话”生成整场表演。
5. **弹窗打断流程。** 33 个 Modal 里很多是一次性操作，却把用户从上下文里拽出来。

## 2. 设计原则（把“苹果式简洁”翻译成可执行规则）

1. **一屏一件事。** 每个阶段只回答一个问题：故事是什么 / 分几镜 / 长什么样 / 怎么演 / 生成了吗 / 怎么剪。
2. **一个主按钮。** 每屏只允许一个强调色按钮（下一步）；其余是次要/幽灵按钮。
3. **渐进披露。** 默认只显示当前阶段需要的 5–8 个控件；参数进右侧检查器，高级项进“⋯”。
4. **一个助手，贯穿全程。** 全局 `⌘K`，按当前阶段提供技能；输出“提案卡”，一键应用、可撤销。不再有并列的三套助手。
5. **直接操纵优先。** 能拖就不填参数；必须填的才用检查器。
6. **费用透明。** 所有生成先报价、显式确认，绝不静默扣积分。
7. **键盘优先。** `⌘1…⌘6` 切阶段、`⌘K` 助手、`⌘Z` 全局撤销、`Space` 播放、`Enter` 主操作。
8. **空状态即引导。** 每屏空状态 = 一句提示 + 一个输入框，而不是空白画布。

### 视觉规则（Apple HIG 取向）

- 字体：SF Pro（回退 -apple-system）；正文 13/15，标题 17/22/28；行高 1.4。
- 网格：8pt；圆角 10（控件）/14（卡片）；分隔线 1px `rgba(0,0,0,.08)`。
- 配色：浅色底 `#F5F5F7`，卡片 `#FFFFFF`，工作区深色 `#1C1C1E`；**一个**强调色（系统蓝 `#0A84FF`，或项目主色）。
- 层级：只有两层——内容面、浮层（sheet/popover）；不再用第三层弹窗。
- 动效：150–250ms ease-out；只用于状态变化和转场，不用于装饰。
- 图标：统一 20pt 线性图标，同一动作永远同一图标。

## 3. 新信息架构

```
┌ 项目库（⌘O）
└ 一部影片
   ├ 1 故事 Story      剧本与设定（文学层）
   ├ 2 分镜 Shots      镜头表（生产工单）
   ├ 3 资产 Assets     角色 / 场景 / 道具（提示词与定稿图）
   ├ 4 预演 Previz     3D 表演与机位（默认助手生成）
   ├ 5 生成 Generate   逐镜首尾帧 + 两条视频路线 + 任务/费用
   ├ 6 剪辑 Cut        时间轴、字幕、导出
   └ 自由画布（高级）   现有节点画布，从项目菜单进入
```

左侧固定 56px 图标栏（6 个阶段 + 项目库），顶部 48px 只放：项目名、当前阶段名、保存状态、导出。
底部（可选）一条助手输入：`⌘K 问点什么，或描述你要的下一步…`

## 4. 每屏做什么（含线框）

### 4.1 故事 Story

```
┌ 故事 ─────────────────────────────────── ⌘K 助手 ┐
│ 场景 1  雨夜 小巷                          右侧：   │
│ 女修被巨力击飞，掠过树枝落入林间……          影片信息   │
│                                           类型/时长   │
│ 场景 2  …                                  风格参考   │
│                                           角色名单   │
│                                              │
│ [+ 场景]                         [生成分镜 →] │
└──────────────────────────────────────────────┘
```

- 主按钮：**生成分镜**（把剧本转成镜头表，出候选、可撤销）。
- 助手技能：续写、改写选段、拆场、给风格建议。
- 不再有“画布节点”；文本就是文本。

### 4.2 分镜 Shots

```
┌ 分镜  12 镜 · 24s ───────────── [生成分镜] [＋镜头] ┐
│ #  缩略图  景别   时长  画面描述          资产      状态 │
│ 01  ▧      大全景 3.0  女修坠入林间       女修/林    ✓  │
│ 02  ▧      中景   4.0  坐地后退，嘴角血    女修       ✓  │
│ 03  ▧      近景   3.0  手中捏诀           女修/手    ●  │
│ …                                                    │
│                                        [送预演 →]     │
└──────────────────────────────────────────────────────┘
```

- 这是全软件的“生产工单”，每镜一个状态：草稿 / 参考就绪 / 生成中 / 待审 / 已采用。
- 点任意一镜 → 右侧检查器（描述、资产引用、时长、提示词），不跳页。
- 合并现有：镜头清单、文稿与分镜、拍摄表。

### 4.3 资产 Assets

```
┌ 资产  角色 6 · 场景 4 · 道具 3 ─────── [生成资产图] ┐
│ [角色] [场景] [道具]                                │
│ ▧ 女修 · 定稿      v3  ← 被 8 镜引用   [查看/重生成] │
│ ▧ 男修 · 定稿      v2  ← 被 5 镜引用                 │
│ ▧ 巨妖 · 定稿      v1  ← 被 4 镜引用                 │
└──────────────────────────────────────────────────────┘
```

- 提示词、定稿图、版本、被引用镜头在同一张卡里；生成走报价确认。
- 合并现有：项目素材、离线资产、资产库、图片版本。

### 4.4 预演 Previz（重点重做）

```
┌ 预演  镜 03 ───────────────── [表演模式] [精修] ┐
│                                                  │
│              3D 视口（16:9）                     │
│                                                  │
│ ─────────────────────────────────────────────── │
│ 时间轴： ▮ 坐地后退  ▮ 捏诀  ▮ 抬头              │
│ 机位：   [全景] [中景] [特写]  ← 预设，不手摆     │
└──────────────────────────────────────────────────┘
```

预演分两层，**职责完全分开**：

- **表演层（AI）**：从剧本 + 分镜生成整场表演——所有角色在什么时候做什么动作、怎么走位、朝向谁。
  产出是一条连续表演时间轴，分镜只是把它切开看；助手**绝不移动或创建摄影机**。
- **机位层（人）**：用户自己摆 10–20 个机位，给每个镜头指定机位与时间区间；可以整段多机位拍下来。
  界面提供机位列表、每个机位的画面预览、按镜头切机；机位参数仍可手动微调。

默认路径：**导入剧本+分镜 → 助手出整段表演 → 你在时间轴审阅 → 自己摆机位 → 多机位录制/导出**。
“精修”只用于微调表演与机位，不改变两层职责。场景/道具用“从资产建场”或“对话建场”。

### 4.5 生成 Generate

```
┌ 生成  逐镜 ────────────────────────── [全部生成] ┐
│ 镜 03  首帧 ▧  尾帧 ▧  参考包(3资产+预演)  26积分  │
│        [生成]  任务：排队中…                        │
│ 镜 04  首帧 ▧  尾帧 ▧  …              未生成       │
└──────────────────────────────────────────────────┘
```

- 两条路线在同一张卡上切换：**首尾帧图生视频** / **预演参考生视频**。
- 费用、任务状态、版本采用都在这页；不再散落 33 个弹窗。

### 4.6 剪辑 Cut

- V1 视频、A1 音频、字幕轨；拖拽、裁切、替换版本；导出。
- 合并现有“剪辑 / 交付 / 导出预演”。

## 5. 3D 导演台为什么“必须自己摆”，怎么改

现状：导演台是通用 3D 编辑器（每对象、每参数、每机位），助手只做局部修改。
目标：**导演台变成“表演预览器”**，默认由助手产出可审阅的初稿。

1. **场景**：模板（森林/室内/街道）+ 从资产一键建场 + 对话建场（“深山树林里一块空地”→ 地面/树/雾）。
2. **表演**：选角色 + 一句话剧情 → 节拍表 → 时间轴审阅；动作从 109 段库检索（v1.23 已具备）。
3. **机位**：自动给全景/中景/特写三组覆盖机位；用户只选，不摆。
4. **精修**：手动摆放、路径、关键帧留在“精修”模式，默认隐藏。

验收标准：**打开预演 → 写一句话 → 60 秒内看到能审的表演**（现有流程要 10 分钟以上）。

## 7. 实施路线（建议 8–10 周，可分阶段验收）

| 阶段 | 内容 | 产出 | 验收 |
|---|---|---|---|
| 0（1 周） | 设计 tokens + 组件层；抽 shell | `design-system.css`、`stage-shell.mjs` | 旧界面不变，新壳可挂载 |
| 1（2 周） | 新壳 + 故事 + 分镜 | 六段 rail、故事编辑器、镜头表 | 灵感→分镜可走通，点击 < 20 次 |
| 2（2 周） | 资产 + 生成 | 资产卡、逐镜生成工单、报价/任务 | 分镜→一镜生成可走通 |
| 3（2–3 周） | 预演重做 | 表演模式、机位预设、建场 | 一句话→可审表演 < 60 秒 |
| 4（1–2 周） | 剪辑 + 导出 + 迁移 | 时间轴、导出、旧画布入口 | 整片导出；旧工程可打开 |

工程约束：
- 项目 JSON schema 不变，新界面是视图层；旧画布数据保留但默认隐藏。
- `main.js` 先拆 `shell / story / shots` 三个模块再动界面；640 项测试保持通过。
- 每阶段 feature flag + 截图验收；不与现有功能抢开关。

## 8. 验收指标（重设计是否成功）

1. **首次成功**：新用户不看文档，10 分钟内完成“建工程 → 剧本 → 分镜”。
2. **路径长度**：灵感 → 第一版分镜 < 10 分钟、点击 < 20 次。
3. **页面切换**：分镜 → 生成一镜，切换页面 ≤ 1 次。
4. **预演**：一句话 → 可审表演 < 60 秒。
5. **界面密度**：每屏可见按钮 ≤ 12；顶层模式 = 1 套。
6. **回收站**：旧画布仍可从“高级”进入，老工程不丢。

---

## 9. 与竞品的差异

OiiOii / Updream / LibTV 都是“画布 + 生成 + 积分”。你的护城河不是画布，是
**影视流水线（剧本→分镜→资产→预演→生成→剪辑）+ 分镜工单 + 白模预演**。
把这条流水线直接做成界面结构，用户第一次打开就理解你比竞品多什么；藏在工具箱里则等于没有。
