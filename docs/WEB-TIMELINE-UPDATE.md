## 时间轴

- 单击菱形选中关键帧，左右拖动修改时间。按帧吸附，不会覆盖同轨已有关键帧。
- 选中后按 Delete / Backspace，或点「删除所选」。删除的是关键帧，不是角色。支持 ⌘Z / Ctrl+Z 撤销。
- 整体关键帧与单参数关键帧均可拖动/删除，关联的贝塞尔手柄会相应迁移或清理；仍被其他位置轨道使用的手柄会保留。
- 绿色动作片段：拖两端调整起止时间，拖中间整体移动，双击修改参数。片段自动避让同角色相邻片段，最短一帧；锁定对象不能编辑。
- 拖动中按 Esc 或窗口失焦取消。一次拖拽只形成一个撤销步骤。
- 拉长片段增加播放持续时间，保持设定速度并循环；要加快或减慢表演，在双击弹窗里改「播放速度」。肢体动作与空间走位关键帧分开控制。

## 导入模型也能编排动作

选择模型 →「动作库 / 播放」→ 搜索或选择动作 → 设置起止时间 →「添加到时间轴」。此时可像内置角色一样拖动、删除和撤销片段。

保留旧工程的整段循环设置，改名为「片段外默认动作（循环）」；有片段时优先播放片段，结束后恢复默认动作。骨骼时间从片段起点开始，并应用该片段速度。每个模型只能使用自身骨架所带动作，未实现自动跨骨架重定向。

## 沿路径行走（2026-10-11）

选择角色，在右侧「动作」中点击「沿路径行走」。需要至少两个不同时间的位置关键帧，并且路径有连续水平位移。离线模型使用它自身的骨骼动作，自动选择已识别的步行动作；没有可识别动作时需要手动选择，没有动作的静态模型会提示先绑骨或导入动作。

默认区间覆盖首尾位置关键帧，生成可拖动、裁剪、双击编辑和删除的表演片段。片段内实时取样原有直线或贝塞尔路径，自动转向；停止位移时停止迈步，片段结束保留最后朝向，后续动作或旋转动画可接管。步频控制动作循环速度，移动速度仍由位置关键帧决定，尚不包含自动步幅匹配和足底锁定。模型正面朝向不同可通过朝向修正补偿，通常为 180°。请选择原地循环动作，含根位移动作会叠加位移。

重叠动作默认禁止覆盖，明确勾选替换后才替换区间内部分，并保留区间外片段。动作设置随项目保存，操作支持撤销。原有位置、旋转关键帧和贝塞尔控制点不被重写。

验证：新增 6 项测试，覆盖曲线朝向、暂停、确定性跳帧、片段裁剪、重叠替换、锁定、项目往返及非法数据。全套 110 项通过，6 项服务器测试跳过。网页构建通过。浏览器实际播放核验因访问授权被拒绝而未完成。

## 沿路径奔跑与替换提示（2026-10-11）

- 右侧「动作」新增独立的「沿路径奔跑」入口；沿路径动作窗口可切换行走 / 奔跑，自动匹配当前模型的前向跑步、慢跑或冲刺循环。无匹配时要求手动选择，不自动以行走动画代替。
- 动作类型保存在 gait 字段，旧项目可根据 pose 或 clip 推断类型。时间轴显示对应名称，双击编辑保留类型。切换步态不会改变位置关键帧及到达时间，移动速度仍由位置关键帧控制。
- 重叠动作以金色提示区列出片段名称和起止时间；大尺寸替换按钮需明确选中，提交按钮随后显示「替换并添加到时间轴 / 替换并保存」。改变起止时间会清除替换选择，避免误覆盖其他区间。区间外动作保留，支持撤销。

## 时间轴框选关键帧（2026-10-11）

- 在轨道空白处按住左键拖拽，框选已展开轨道中的关键帧，可跨对象、跨参数。框选靠近时间轴上下边缘会自动滚动。锁定对象不参与框选。
- Shift + 框选追加选择；Shift + 单击关键帧追加 / 取消。点击空白处清空选择并定位时间，顶部标尺仍用于拖动播放头。
- 拖动任一已选关键帧可整体平移，保留时间间隔，整组限制在时间轴内；遇到未选关键帧或贝塞尔手柄冲突时阻止覆盖。
- Delete 或「删除所选」批量删除；整组移动、删除各占一次撤销。Esc 取消当前拖拽，恢复此前选择 / 时间 / 数据。折叠轨道清除该对象的关键帧选择。
- 验证：全套测试通过后，补充贝塞尔目标手柄冲突检查，6 项多选专项测试全部通过；网页构建通过。本次未访问此前拒绝授权的浏览器，未完成鼠标操作实测。

## 导出时简化角色外形（2026-10-11）

「导出预演」新增默认关闭的「简化角色外形」。启用后选择人物，可先预览当前帧；选项同时应用于截帧和 WebM 导出。替身由躯干、头部及朝向标记构成，没有四肢和服装细节，适合表达构图与站位，不表达肢体表演。

人形角色由离线资产 category=character 或生成节点 modelKind=human 识别。已知动物、怪物和场景不参与；未知自导入 GLB 默认不选，需手动确认。替身按原模型静态高度构建，跟随对象级位置、朝向、缩放及位置路径。骨骼自身的局部表演和根位移不映射到替身。

替身仅在单次同步渲染中加入场景；每帧结束或渲染失败后立即移除并恢复原始可见性，不修改工程几何、材质、骨骼、动作或关键帧。视频导出完成、取消或失败时释放替身资源。隐藏对象保持隐藏，Solo 仍只影响编辑器。

验证：128 项测试，122 通过、6 项服务器测试跳过，构建通过。测试覆盖分类、成人 / 儿童替身高度、变换跟随、隐藏状态、异常恢复和资源释放。沿用此前浏览器授权限制，未做浏览器画面 / 实际录制核验。

## 统一设置入口（2026-10-11）

- 右上角「设置」整合常规、API 服务和存储三个分类；原 API 入口及桌面菜单仍可直接进入 API 服务页。
- 常规设置包含自动保存间隔 / 手动保存、工程备份、恢复默认面板布局和操作指南。工程窗口的保存设置跳转到此处，避免重复维护。
- 存储页显示浏览器项目数据库、用量与配额、持久存储申请，以及本地服务的生成图片、模型、任务和离线资产目录。数据库物理位置由浏览器管理；不提供可能误删项目的缓存清理按钮。
- 本地生成目录可通过环境变量 JINGCHANG_DATA_DIR 配置，界面暂不支持目录选择或自动迁移。更改位置需停止服务、复制已有数据并重启；浏览器项目库及离线资产目录不随之迁移。
- 新增只读 /api/ai/storage 接口，沿用本地来源校验，不返回凭证、不触发生成任务。本次未重启现有服务，以保留内存中的 API 配置；旧服务会提示重启后读取目录。
- 验证：129 项测试，123 通过、6 项服务器测试跳过，网页构建通过；遵守此前浏览器授权限制，未做界面实测。
