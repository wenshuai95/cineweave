# 生成页节点画布 · 设计方案（v1.31 目标）

## 为什么

现在的生成页是“逐镜列表 + 按钮”。你需要的是一张**可连线的素材图**：
资产图、镜头首尾帧、预演片段作为素材节点，连到视频生成节点，选模型、报价、生成、采用。
这样图生视频、文生视频、白模预演多素材参考生视频就是同一张画布上的不同连法。

## 节点类型

| 节点 | 来源 | 输出 |
|---|---|---|
| 资产图 | 资产页已生成的定稿图 | 图片 |
| 镜头首帧 / 尾帧 | 分镜镜头（生成或上传） | 图片 |
| 预演片段 | 预演页导出的镜头视频 | 视频 |
| 参考视频 / 音频 | 本机媒体库 | 视频 / 音频 |
| 提示词 | 手写或从镜头/资产生成 | 文本 |
| 视频生成 | 选模型 + 类型（文生 / 图生 / 多参考） | 视频 |
| 成片镜头 | 生成结果采用后 | 视频（供剪辑页使用） |

## 交互

- 画布：拖动平移、滚轮缩放、框选；节点卡片拖拽；`⌘K` 助手按选中节点给建议。
- 连线：节点右侧输出端口 → 目标节点左侧输入端口；输入槽按模型能力显示：
  - 文生视频：提示词
  - 图生视频：首帧（必填）+ 尾帧（可选）
  - 多参考：首帧 + 资产图/参考视频（数量按模型 media 契约）
- 生成节点：模型下拉（含积分报价）、时长、提示词；「报价」→「确认生成」→ 进度 → 结果。
- 结果：在节点上直接预览；「采用」把视频挂到镜头，剪辑页可用。

## 数据

过渡方案：`localStorage` 按 projectId 保存节点位置与连线（不污染工程 JSON）。
正式方案：新增 `project.workstation.generationGraph = {nodes:[...], edges:[...]}`，
并在 `validateProject` 里做上限与格式校验（nodes ≤ 200，edges ≤ 400，坐标有限数）。

## 已实现（v1.31）

- 画布壳：平移、缩放、节点拖动、选中；节点位置存 localStorage。
- 素材节点：资产图（无图显示占位）、镜头、预演片段；生成节点；结果节点。
- 连线：点素材右侧圆点 → 点生成节点左侧圆点；点连线删除；「重置连线」恢复默认。
- 生成：模型下拉（按参考能力优先）、提示词、报价确认、轮询、结果挂到镜头；列表视图可切换。

## 实施拆分

1. **G1**：画布壳（平移/缩放/节点拖拽/选中）+ 从工程数据生成素材节点与生成节点。
2. **G2**：端口连线 + 输入槽校验 + 提示词/模型/时长参数。
3. **G3**：接 `video-jobs`：报价确认、提交、轮询、结果预览、采用到镜头。
4. **G4**：结果节点进入剪辑；预设模板（“首尾帧→图生”、“预演+资产→多参考”）。

## 风险

- oiioii 视频参考契约：参考数量/用途由模型 media 能力决定，需要按模型动态渲染输入槽。
- 图生视频需要首尾帧文件；首帧可来自资产图或镜头截图，尾帧需要“生成尾帧”能力，后续补。
- 画布与现有列表并存：列表保留为“表格视图”，画布为默认。
