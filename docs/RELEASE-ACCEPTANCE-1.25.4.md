# 造梦工坊 v1.25.4 交付验收

日期：2026-10-24
版本：1.25.4

## 一、产品边界

造梦工坊服务**已有剧本/分镜**的创作者：

- 导入剧本参考
- 手工维护镜头表
- 管理角色/场景/道具资产
- 3D 白模预演
- 本地 ComfyUI / 云端 Seedream 生图
- 视频 Provider 生成
- 粗剪、导出

明确不做：

- 不生成剧本、大纲、对白
- 不做创作助手对话
- 不做 AI 自动分镜/资产设计
- 不自动下载 H3 模型

## 二、已验证流程

### 首次与项目

- 首次启动配置向导
- 项目库 / 新建项目
- 空白项目首屏：导入剧本、新建镜头、导入素材

### 剧本与镜头

- 导入/粘贴已有剧本
- 剧本只读参考节点
- 手工镜头表：新增、编辑、删除、保存
- 六阶段导航：剧本 / 镜头 / 资产 / 预演 / 生成 / 剪辑

### 资产

- 手工新增角色/场景/道具
- 导入本地图片
- 选择正式图
- 更新画布节点
- 无 AI 设计/文字模型入口

### 3D 导演台与白模

- 机位/走位/动作/关键帧
- 截图到画布、深度图
- 按镜头导出白模参考视频包
- 每镜 MP4 + manifest + README
- 自动 24fps 规范化
- 实测 3 镜全部 24fps

### 生成

- 统一生成面板
- ComfyUI / Seedream 图片
- ComfyUI 图生图
- Seedance/Kling 首帧参考
- 费用确认、任务持久化
- 最近生成恢复
- 同源候选、加入资产版本、设为正式图
- 视频结果保存素材库 / 送入剪辑

### H3 接口

- 设置页检测 H3 节点与模型
- 缺模型时提示缺少项
- 不自动下载、不阻塞现有生成
