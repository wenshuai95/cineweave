# 造梦工坊 UI 2.0 计划：即梦画布 + 基础剪辑 + 素材库

## 目标

1. 画布做到“即梦同构”：布局、节点、工具、交互、视觉层级一致，不做“差不多”。
2. 生成能力只保留 API 接口：即梦能生成的，造梦工坊通过 Provider 接口生成；本阶段不新增真实付费 API 联调。
3. 剪辑面板达到“基础剪辑可用”：导入、素材库、V1/A1 时间线、裁切、分割、移动、删除/闭合、播放、逐帧、缩放、撤销、快捷键、导出；不做转场/特效。
4. 素材库：外部素材导入 + 画布节点素材，可搜索/筛选/预览/拖入时间线/复用。
5. 3D 导演台保持现状，不继续开发。

## A. 即梦画布同构

### A1 视觉壳层（P0）
- 画布全屏、深色点阵，无多余品牌大标题。
- 左上：项目名 + 节点数 + 已保存；右上：搜索/分享/更多；底部：缩放 + 选择/抓手 + “与 AI 对话”。
- 左侧窄竖排工具条：文本/图片/视频/音频/镜头表/3D/上传；图标、间距、选中态与即梦一致。
- 中央空画布提示“双击画布 / 创建节点”。

### A2 节点（P0）
- 节点无重标题栏/类型 badge/状态行；类型标签浮在卡片外上方。
- 空节点只显示类型图标；图片/视频/音频结果铺满卡片。
- 失败才显示原因 + 重新生成；运行中只留细进度。
- hover 工具、选中描边、连接点、缩放手柄克制。
- 文本节点像即梦一样直接可读，不套编辑器壳。

### A3 创建与画布交互（P0）
- 双击空白创建菜单；左栏单击创建；拖动到画布创建。
- 框选、多选、移动、缩放、复制/粘贴、删除、撤销/重做。
- 连线、断线、重连；连线类型区分图片/视频/音频。
- 网格/吸附、层级、对齐、适应画布、快捷键。
- 右键菜单与即梦一致（重命名/复制/删除/连接/生成）。

### A4 节点生成卡（P1）
- 真实即梦：选中**空节点**后，生成卡贴在节点下方（实测 680×206，圆角 20，blur 24），不是屏幕底部弹窗。
- 选中已生成图片：节点上方出现浮动编辑工具栏，不显示生成卡。
- 参考分组、模型、比例/分辨率/时长、prompt、费用/生成。
- 详细尺寸见 `docs/JIMENG-INTERACTION-SPEC.md`。
- Provider 只使用现有接口；新增能力先加 capability/descriptor，不写死厂商。

## B. 剪辑面板

### B1 基础剪辑（P0）
- 素材库导入：视频/音频/图片外部文件。
- 画布素材：视频/音频节点、导演台预演、剪辑输出可加入素材库。
- 时间线：V1 视频 + A1 音频；拖入、移动、入出点裁切、分割、删除、闭合空隙。
- 播放：Space、J/K/L、←/→ 逐帧、Home/End、I/O 入出点、播放头拖动。
- 快捷键：⌘Z/⌘⇧Z、Delete、S 分割、F 适应、+/- 缩放、⌘S 保存。
- 缩放/吸附/时间码；选中片段 inspector：位置、入出点、音量、静音。
- 撤销/重做、保存/恢复、导出 MP4、送入画布。

### B2 素材库（P1）
- 左侧素材库：缩略图、名称、时长、来源（外部/画布/预演）、筛选、搜索。
- 预览、拖入轨道、双击加入、删除/移除；外部文件导入持久化。
- 空状态、导入失败、素材缺失可恢复。

## C. 验收

- 1440×900 / 1024×768，无横向溢出、console exception=0。
- 画布：空→创建→连线→多选→移动→删除→保存→重开恢复。
- 剪辑：导入→拖入→裁切→分割→删除→撤销→导出。
- 素材库：外部导入 + 画布素材 + 搜索/筛选 + 拖入。
- npm test / build；不调用付费 API，不安装 H3。

## 分工

- ZCode：A1/A2 画布视觉与节点（先做 A1+A2，小步提交，不碰 Provider）。
- WorkBuddy：A3/A4 交互、B1/B2 剪辑与素材库、真机验收与发布。
- Lead：审核、测试、发布。

## 当前不做

- 转场、特效、调色、字幕模板。
- 真实 Seedance 2.5 付费联调（保留接口）。
- AI 编剧/自动分镜/自动资产设计。
- 3D 导演台新功能。
