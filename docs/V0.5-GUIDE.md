# 镜场 v0.5 使用说明

## 离线模型库

导演台顶部「模型库」可按人物、动物、汽车、房屋、环境分类加入模型；也可导入内嵌纹理的 GLB（最大 40 MB）。20 项下载资产均附 CC0 许可、来源、推荐尺寸与 SHA256，详见 `public/assets/manifest.json`、`public/assets/licenses/`。纹理已嵌入，离线运行不再访问来源网站。

人物 4 个、动物 4 个、汽车 4 辆、房屋 3 栋、环境 5 件。人物/动物带原生动画，在属性底部「模型原生动画」选取，再播放时间轴。动画按整个工程时间播放，尚未提供导入骨骼之间的自动重定向、任意动作融合或逐片段混合。场景位置关键帧可同时使用。外部模型保留原材质，标识颜色不重新染色。

库内资源引用随工程保存，换电脑需同时带上软件资产包；自行导入的 GLB 以内嵌数据保存在工程 JSON 中。公共资产也已放到 dist，直接运行不需要构建。

## 摄影机画幅与导出

摄影机属性「画幅」支持 16:9、2.35:1、9:16，影响监看、PNG 与视频构图。默认输出分别为 1280×720、1410×600、720×1280；画幅是机位设置，不随关键帧改变。

「导出预演」中选择固定机位或按剪辑切机，设置开始/结束时间。固定机位沿用该摄影机画幅；混合画幅切机可选择输出画布画幅，不匹配的机位加黑边保留完整构图。输出为 WebM，音频节点目前仅作参考，不自动混入预演。

## 路径与贝塞尔

对象有至少两个位置时间点后会显示轨迹。点击轨迹选对象；点击金色关键位置圆点，调出 XYZ 操作杆，修改该时间的空间位置。右侧「编辑当前时间的贝塞尔手柄」可编辑入柄/出柄偏移，保存后场景显示青色入柄、紫色出柄。点控制柄，再拖 XYZ 修改曲线。可整体撤销。

贝塞尔作用于位置，注视点仍使用原有独立 XYZ 通道。已有手柄的区间优先按三次贝塞尔采样；其他区间保留原有插值。贝塞尔参数与时间线性对应，不是恒定空间速度。当前为自由控制柄，没有自动对称/切线锁定。密集运镜预设的路径点较多，建议先短区间编辑。

## 锁定与 Solo

场景列表每个对象右侧有锁定和 S。锁定禁止该对象的属性、变换、关键帧、删除和动作编辑，允许查看与播放。S 可多选独显：实体对象之间一组，摄像机辅助图标之间一组。Solo 仅隔离导演视角；监看、截图和导出均显示完整实体场景。锁定/Solo 随工程保存，可撤销。

## 画布节点

空白处右键新建文本、图片、视频、音频节点，节点出现在右键位置。媒体节点通过右侧「导入 / 替换素材」填充；音频带播放控件，支持 MP3/WAV/OGG/M4A 等浏览器可播放格式。媒体上限 25 MB。右键不平移画布。

## 旧版媒体 CLI 图片生成

AI 接口→旧版媒体 CLI 文生图，或文本/图片节点属性→旧版媒体 CLI 生成图片。读取当前账号的模型、尺寸与画幅；填写描述，查询积分，再点击确认提交。报价以平台结算为准，只有提交会发起生成。任务完成后下载到本机、加入画布；「恢复上次图片任务」可继续读取最近任务。提交结果不确定时不自动重试，先到 旧版媒体 CLI 核对。

当前接入文生图，没有自动将已有图片上传作图生图参考。提示词、模型与画幅会发送到 旧版媒体 CLI；本地画布其他内容不会自动发送。需要网络、官方 CLI 授权和当前工作空间。当前电脑已验证授权、目录与报价；未用真实收费任务验证最终生成。模拟 CLI 已验证提交去重、轮询、图片下载与回传。

CLI 默认位置 `~/.local/bin/旧版媒体 CLI`，可通过 `旧版媒体 CLI_CLI` 环境变量指定。新电脑自行安装官方 CLI 并登录；软件包不含任何账号凭证。生成任务及下载文件保存在软件目录 `.local/`，不纳入发布包。关闭网页后可恢复；服务重启导致仍处于提交中的任务需到平台核对。

## 文字动作、图文场景

基础人偶属性→文字编排动作：本地规则支持如「向前走2米3秒，然后挥手2秒」。生成的是现有动作片段与位置关键帧；先预览，点采用后写入。复杂语句选 DeepSeek。

文本/图片节点属性→图文编排3D场景：读取该节点和直接相连的文本、最多两张 PNG/JPEG/WebP 图片。离线规则只按文字类别放置少量资产；DeepSeek 可根据描述和图像规划资产、位置、朝向、比例。采用后添加对象，保留原场景。它生成布局，不生成新的几何网格，也不保证精确重建参考图。

DeepSeek 只在用户点击云端规划时发送所示描述、图片及角色当前位置。方案经过白名单、坐标与区间校验；不会执行模型给出的代码。API 密钥通过本地启动环境提供，不写入工程、网页或输出日志：

```sh
# 在软件目录打开终端，先停止已运行的服务。
read -s 'DEEPSEEK_API_KEY?输入 DeepSeek API Key（隐藏输入）: '
export DEEPSEEK_API_KEY
export DEEPSEEK_BASE_URL='https://api.deepseek.com'
export DEEPSEEK_MODEL='deepseek-flash'
npm start
```

以上为 Mac 默认 zsh 命令。本软件未拿到你的 DeepSeek 密钥，因此云端规划未实测；若你使用第三方服务商，填写该服务的 HTTPS 基础地址与实际模型 ID。

DeepSeek 适合编排。生成全新骨骼动作推荐 HY-Motion 云 API；生成新网格推荐 Meshy / Tripo，获得 GLB 后导入。相应服务尚未接入软件；比较、官方链接与硬件需求见 `AI-RESEARCH.md`。
