# 流水线界面（阶段 0+1 原型）

新界面是旧界面的**并行视图**，读写同一个项目库；旧界面保持不动。

## 打开方式

- 应用内：设置 → 新版界面（测试）→「打开新版界面」
- 浏览器/调试：`http://127.0.0.1:<端口>/pipeline.html`

第一次打开会列出项目库；也可以「新建示例影片」直接体验。左侧六个阶段用 `1–6` 切换；`⌘K` 打开助手占位。

## 已实现（阶段 2）

- 设计系统：颜色/字体/间距/圆角/阴影 tokens，组件样式统一。
- 六段式外壳：故事 / 分镜 / 资产 / 预演 / 生成 / 剪辑；项目切换、保存状态、键盘切换。
- 故事：剧本编辑、自动保存、场次大纲、影片信息。
- 分镜：镜头表（编号、时长、画面描述、机位、状态）；**可新建、改时长、换机位、改描述、上移/下移、删除**，
  时间轴自动重排、自动扩展总时长；描述写回画布文本节点。
- 助手（⌘K）：**续写/改写剧本**、**生成分镜**；提案先预览，应用后替换或追加，并给一次撤销。
- 资产：提取角色/场景/道具（助手）、编辑提示词、**生成资产图**（可选模型 → 查询报价 → 确认生成 → 轮询 → 采用）；生成图可点击放大查看/下载。
- 生成：**嵌入旧画布**（`?embed=canvas`）——节点、连线、素材、生成任务全部沿用旧画布。
- 预演：**整台旧导演台原样嵌入**（`/?stageOnly=1&project=<id>`，iframe）——
  场景对象/离线模型库、拖拽手柄、机位目标点、路径与贝塞尔手柄、逐参数曲线轨道、快捷键（WASD/QE/IJKL、1/2/3、G、Delete…）、
  时间轴（关键帧/动作/运镜/镜头编排/表演编排）、右侧属性面板与机位监看，全部沿用旧实现。
  新界面只保留顶部的“重新载入 / 新窗口打开”，其余布局与旧导演台一致。

## 预演嵌入的响应式（v1.35）

嵌入旧导演台时取消了旧应用的 `min-width:1000px`，并按宽度自适应列宽：

| 窗口/iframe 宽度 | 左栏 | 右栏 |
|---|---|---|
| ≥1180 | 190px | 240px |
| ≥980 | 170px | 215px |
| ≥840 | 150–170px | 190–215px |
| ≥700 | 132px | 170px |
| <700 | 0（隐藏） | 160px |

低高度时压缩时间轴（≤640px 高：158px；≤540px：138px 并隐藏辅助导航），预演页会隐藏底部助手条把空间让给导演台。
实测 1440×900 / 1280×720 / 1024×768 / 900×760 / 820×700 / 780×700 / 720×680 均无横向溢出、时间轴与画布在视口内。


## 六段与旧界面的对应（v1.36）

| 阶段 | 实现 |
|---|---|
| 故事 | 新版故事编辑器 |
| 分镜 | 新版镜头表 |
| 资产 | 新版资产卡与生成 |
| 预演 | 嵌入旧 3D 导演台（`?embed=stage`） |
| 生成 | 嵌入旧画布（`?embed=canvas`） |
| 剪辑 | 嵌入旧剪辑面板（`?embed=edit`） |

嵌入页统一带「重新载入 / 新窗口打开」；切回故事/分镜/资产时会等待旧应用保存并从项目库刷新。
