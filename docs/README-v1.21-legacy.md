## 网页版启动

在 Mac 上双击 **启动超级无敌导演画布.command**，打开 `http://127.0.0.1:4173`。需要 Node.js 20+（本机已安装）。保持启动的终端窗口打开；关闭它会停止服务。

也可以在此目录运行：

```sh
npm start
```

交付包已经包含 `dist` 编译文件。日常运行不需要 npm install，也不依赖 CDN 或联网。仅监听 127.0.0.1，不向局域网开放。建议使用较新版本的 Chrome 或 Edge，屏幕宽度至少 1100 像素。WebGL 和 MediaRecorder 为必需浏览器能力；Safari 的 WebM 支持可能不同。

## 已实现

- 无限画布：拖动、缩放、适应画布，文本 / 角色 / 场景 / 导演台 / 图片 / 视频节点，引用连线。
- 本地素材导入：PNG、JPEG、WebP、GIF、MP4、WebM，单文件上限 25 MB。
- 资产关联：角色节点可创建三维人偶；改名双向同步。
- 三维场景：基础人偶、方块、墙体、长桌、立柱、摄影机；位置、朝向、统一比例和颜色。
- 基础角色动作：站立、行走、跑步、坐姿、指向、挥手、举手欢呼。位移由关键帧单独控制；这些是程序化基础动作，并非真人动作捕捉。
- 相机：位置、视场角、注视点、实时监看；透视 / 顶视 / 正视和聚焦对象。
- 独立参数关键帧：位置 XYZ、朝向、比例、颜色、FOV、注视点 XYZ 与姿态；平滑、匀速、保持过渡；轨迹线、播放、时间定位、关键帧编辑与删除。
- 镜头编排：设置摄影机的生效时间区间，播放与导出自动切机。
- 输出：按机位画幅导出 PNG / WebM，可选单机位、切机和时间区间；输出自动回到画布。
- 工程：IndexedDB 自动保存，JSON 导入导出，撤销 / 重做，内置三机位示例。
- AI：oiioii 文生图、可配置的 DeepSeek 规划适配器；离线动作/场景规则。详见 docs/V0.5-GUIDE.md。

## v0.4 独立参数关键帧

- 每个可做动画的属性旁有「◇」按钮：位置 XYZ、注视点 XYZ、朝向、比例、颜色、FOV、角色动作。各轴单独记录，不会顺带为其他参数打帧。
- 「◆」金色菱形表示当前时间已有此参数关键帧，再点会更新同一帧。先在起始时间打帧，再移动时间轴调整参数；已启用动画的参数会自动记录新帧。
- 选中对象后，时间轴展开其参数轨道。双击蓝色菱形可修改时间、数值、过渡或删除。删除最后一个参数关键帧会保留当前值并停止该参数动画。
- 顶部「添加关键帧」与右侧整组记录按钮仍可一次记录整个对象。工程时长、帧率、片段起止时间、过渡选项和预设幅度属于设置，不添加动画关键帧。
- 数值和颜色支持平滑、匀速、保持；角色动作是离散切换，动作片段在其时间区间内仍优先。
- 旧工程可直接打开。首次为旧动画添加单项关键帧，会继承该参数的原有时间点；独立参数轨道随后优先于旧整组关键帧。运镜预设会同步修改已有的相关参数轨道，保留无关参数动画。
- 参数轨道随自动保存、撤销重做和 JSON 工程保留。新工程需使用 v0.4 或更新版本打开，旧软件不识别新增参数轨道。

## v0.3 新操作

### 摄像机红色注视点

选择摄影机，红色注视点默认显示 XYZ 三轴手柄（X 红、Y 绿、Z 蓝），与机位手柄同时可用，拖动箭头只改一个轴。右侧「聚焦注视点 XYZ」可聚焦红点。注视点坐标下方的「记录含注视点的关键帧」会记录当前机位位置、注视点和 FOV；再移动时间轴、调整红点，就能添加下一关键帧。点击工具栏的移动 / 旋转可回到机位编辑。「隐藏红点」仅隐藏编辑辅助，不改变机位朝向。

编辑时监看会切换到该机位。红点、连线和手柄不会出现在 PNG 或 WebM 中；已有动画的机位会在当前时间写入关键帧。

### 数值滑动

所有启用的数字输入框都支持按住左键左右拖动：向右增加、向左减少；Shift 精调；Esc 取消。位置、注视点、FOV、比例、朝向、时长、关键帧时间、镜头区间及预设参数均适用。普通点击仍可输入数字，拖完松开一次提交，整次拖动只占一次撤销。位置等场景参数拖动时实时预览；时间设置在松开时校验。颜色和枚举下拉框不是数字输入框。摄影机方向由注视点与镜头滚转共同控制。

### 角色动作片段

时间轴顶部「＋ 角色动作」或角色行的「＋」可添加动作，设置起止时间和 0.1–4 倍速度。绿色片段可点击修改、换动作或删除；同一角色不能重叠。动作仅覆盖片段内的肢体姿态，结束后恢复原姿态。人物走位仍由位置关键帧控制，因此可以同时走位与挥手。片段随 JSON 工程及自动保存保留。

### 运镜预设

时间轴「＋ 运镜」、机位行「＋」或摄影机属性的「运镜预设」支持：推进、拉远、左移、右移、升镜头、降镜头、左环绕、右环绕、左摇、右摇、变焦拉近、变焦拉远。指定时间、幅度与速度变化后生成普通关键帧，继续双击菱形编辑，或整体撤销。

预设替换指定区间内的机位关键帧，保留区间外关键帧；结束后平滑接向下一关键帧，没有后续关键帧时保持最终状态。环绕以红点为中心；横移和升降同时移动机位与注视点；变焦只改变 FOV。预设不自动修改切机表，导出前请在「镜头编排」确认机位的使用时间。

## 第一次使用

1. 打开示例「雨后会面」，观察画布上的剧本、角色、场景和预演入口。
2. 切换「3D 导演台」，点播放，查看人物从左侧行进，及 6 秒、9 秒的切机。
3. 选择角色，在 0 秒点击「添加关键帧」；移动到另一个时间，修改右侧位置，系统会为已有动画记录当前帧。
4. 选择相机，调整位置、FOV 与注视点；在「镜头编排」设置切机时间。
5. 「截图到画布」用于构图参考；「导出预演」录制完整时间轴。
6. 通过「工程 → 导出工程」备份。项目文件包含导入素材，体积可能较大。

导演台操作已按 2026-10-10 实际查看的即梦画布「3D 预演节点 → 导演台 → 快捷键」及视角操作说明对齐：

| 操作 | 快捷键 / 鼠标 |
| --- | --- |
| 选择 / 移动 / 旋转 / 缩放 | 0 / 1 / 2 / 3 |
| 视角前进 / 左移 / 后退 / 右移 | W / A / S / D |
| 视角下降 / 上升 | Q / E |
| 视角上转 / 左转 / 下转 / 右转 | I / J / K / L |
| 加速导航 | 按住 Shift |
| 转向 / 平移 | 左键拖动或滚轮 / 右键拖动 |
| 调整导演视角的视野 | Alt＋滚轮、触控板捏合或 − / = |
| 移动选中物体（X / Z） | 方向键，每次 0.1 米 |
| 落到地面 | G（人物与道具按当前白模外包围盒落地） |

镜场另外保留：空格播放 / 暂停，Delete 删除对象或节点，⌘Z 撤销，⌘⇧Z 重做，⌘S 保存。记录关键帧使用「◇ 添加关键帧」按钮；双击时间轴菱形编辑关键帧。输入框和弹窗内停用场景快捷键；切换窗口或页面后台时停止持续导航。

导演视角用于查看片场，导航不会改变机位监看或导出画面；拍摄机位仍在右侧属性中编辑。本次对齐的是核心导航、工具切换和对象操作，未逐项复刻即梦的静态 / 动态模式、姿势编辑与全部面板，移动速度和手感也并非逐像素一致。

## 第一版边界

- oiioii 已接入文生图；没有图片自动重建新网格、AI 生视频或新骨骼动作生成。
- 支持自包含 GLB 与原生动画；暂无 FBX、跨骨架重定向、音轨混音、多人协作、多场景管理或原生 Mac 应用。
- 多个导演台节点均指向当前工程的同一个三维场景。
- WebM 是浏览器实时录制，需保持页面前台。帧率是目标值，性能不足时可能掉帧；切到后台会取消录制。需要 MP4 时请另行转码。
- 场景对象最多 300 个、画布节点最多 500 个、时长 1–120 秒。短场景预演优先，复杂场景性能依赖本机。
- 自动保存绑定当前浏览器和 `http://127.0.0.1:4173` 地址。清理网站数据、换浏览器或换端口不会自动迁移工程。导出 JSON 是独立备份。
- 三维编辑是预演参考，最终 AI 生成是否遵循，取决于后续模型与素材。
