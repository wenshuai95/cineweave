研究方式：真实即梦画布 + 官方 Canvas CLI；未修改即梦侧任何工程。

## 一、研究范围与预算

- 图片：Seedream 5.0 Lite，2K，1 张；报价 0 积分
- 视频：Seedance 2.5，t2v 5s/480p，失败；报价 60 积分

- 未做：长视频、音频、多人参考、时间轴、完整协作/分享

## 二、空画布

真实观察：

- 全屏深色无限画布 + 点阵网格。
- 中央只有一句“ 双击画布 / 创建节点 ”，没有工具表单。
- 左侧是一条窄的竖排工具条：文本、图片、视频、音频、表格/画板、脚本、素材、上传等图标。
- 左上：项目名 + 节点数 + 已保存状态。
- 右上：搜索、分享、更多、积分、头像。
- 左下：缩放 - / 比例 / +；底部中间是选择/抓手/整理/适配等小图标；右下是“与 AI 对话”。

关键不是“工具多”，而是：**画布空白时只保留创建入口，所有参数等选中节点后再出现。**

## 三、节点视觉

真实观察：

- 节点上方只有一行很轻的类型标签：`T 剧本 / 镜头说明`、`图片 1`、`视频 1`、`音频 1`。
- 节点卡本身无重标题栏、无类型 badge、无状态栏。
- 空节点是深灰圆角卡片，中间只有类型图标。
- 有结果的图片/视频直接铺满卡片，不额外显示“生成成功”等文字。
- 失败节点才在卡内显示：
  - “视频生成失败”
  - 具体原因（截图中为内部原因）
  - “重新生成”按钮
- 节点之间可以连线；选中后应出现上下文工具与编辑卡，而不是永久属性栏。

## 四、节点类型与创建

即梦画布顶层创建类型至少包括：

- 文本/脚本
- 图片
- 视频
- 音频
- 表格/画板
- 素材上传

对造梦工坊的映射：

| 即梦 | 造梦工坊 |
|---|---|
| 文本/脚本 | 剧本参考 / 文本节点 |
| 图片 | 图片节点 / 资产参考图 |
| 视频 | 视频生成节点 |
| 音频 | 配音/音乐节点 |
| 表格/画板 | 手工镜头表 / 资产表 |
| 素材上传 | 本地素材 |
| 3D 导演台 | 保留，作为白模预演节点 |

## 五、生成结果

图片成功：

- 结果直接替换节点内容。
- 节点仍只有顶部类型标签。
- 没有额外成功状态条。

视频成功：

- 视频卡片带播放按钮。
- 结果直接铺在节点内。
- 顶部标签如 `研究 · 图生视频`。

视频失败：

- 节点内显示失败原因与“重新生成”。
- 不会把失败包装成“已完成”。

## 六、造梦工坊当前差距

1. 节点有重标题栏、类型 badge、状态行，信息过载。
2. 画布顶部常驻工具栏/筛选/阶段导航，空白画布不够干净。
3. 属性栏常驻或弹窗表单感强，不是即梦式“选中后底部生成卡”。
4. 生成面板已接近，但仍是居中 modal，不是贴在画布底部的 composer。
5. 画布节点视觉不够统一：图片/视频/文本卡片样式差异大。
6. 缺少即梦式左侧竖排创建工具条。
7. 创建节点入口分散在“新建”菜单、空画布、工具栏，需统一。

## 七、目标：造梦工坊 = 即梦式画布 + 本地/多云能力

保留差异：

- 本地 ComfyUI（免费、离线）
- 云端 Seedream / 可灵 / Seedance / 其他 API
- 3D 白模预演与参考视频
- 本地项目、素材、剪辑、导出

## 八、开发计划

### Phase 1：画布外观同构
- 深色点阵画布
- 左竖排工具条（文本/图片/视频/音频/表格/导演台/上传）
- 节点去掉重标题栏，仅保留外部类型标签
- 空节点仅类型图标；成功媒体铺满；失败才显示错误
- 顶部：项目名 / 节点数 / 保存 / 搜索 / 积分或服务状态
- 底部：缩放、选择/抓手、适配；右下 AI 对话（可先保留为本地助手入口）

### Phase 2：创建与选择
- 双击画布打开轻量创建面板
- 左栏图标单击直接创建对应节点
- 选中节点出现浮动工具 + 底部 composer
- 空白画布点击取消选择，隐藏所有工具

### Phase 3：底部生成卡
- 选中图片/视频节点，底部浮出：
  - 大预览
  - 参考 / 模型 / 画幅 / 更多
  - prompt
  - 模型/比例/分辨率/数量
  - 积分或费用 + 生成按钮
- 服务商选择中同时列 ComfyUI / 云端 API
- 生成中节点进度，完成后结果直接替换/追加

### Phase 4：多 provider 与本地
- ComfyUI 本地模型
- Seedream / Kling / Seedance / 通用 API
- H3 仅接口
- 白模参考视频

### Phase 5：验收
- 1440/1024
- 空画布 → 创建 → 生成 → 结果 → 重生成
- 失败、停止等待、历史恢复
- 键盘与可访问性
