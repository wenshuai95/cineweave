# v0.10 · 文字动作入口与模型颜色

## 文字动作

在导演台选中导入的 3D 模型，点击右侧「文字动作 · 骨骼检查」。也可在选中模型时点击时间轴的「＋ 角色动作」，或从画布模型右键 → 模型操作进入。

窗口检测蒙皮网格、骨骼数量和模型自带动作。无蒙皮骨骼时会明确提示先绑骨。可以填写动作描述、1–12 秒目标时长，保存到工程，支持撤销。自带动作可通过窗口中的按钮打开离线动作库。

**本版完成入口和描述草稿，尚未接通云端绑骨、文生动作、动作重定向或生成片段加入时间轴。** 两个云端按钮禁用并标注待接入，不会发送模型或产生费用。API 说明链接指向腾讯官方文档，不能据此认为原图片建模 Key 已有动作权限。

## 修改模型颜色

选中导演台中的模型，向下滚动右侧属性到「模型颜色模式」。

- 保留原材质：显示模型文件原本的纹理与颜色。
- 纹理染色：保留原有图案，叠加所选颜色；深色原图可能使结果较暗。
- 统一纯色：整体覆盖底色，不使用底色贴图、顶点色和发光贴图；保留原有形状及其他材质细节。

使用颜色选择器指定任意颜色，或点击蓝、红、白快捷按钮。颜色旁的 ◇ 可记录当前时间关键帧。模式对整段生效，不做模式切换动画；「恢复原色」保留颜色动画数据，再切回染色或纯色可以继续使用。

调整只作用于所选对象，不会把相同模型的其他实例一起改色。模型锁定后不能修改。支持撤销、工程保存和恢复。

当前是整体改色，不会自动识别衣服、皮肤等语义区域。改色会出现在导演视图、机位预览、截图和预演视频；工程 JSON 保存设置。「下载模型 GLB」仍导出原始资产，不会将编辑颜色重新烘焙进 GLB。
