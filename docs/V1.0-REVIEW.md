# v1.0 使用体验与回归检查

## 本次调整

- 品牌、窗口标题和安装包统一为「超级无敌导演画布」，保留旧工程数据格式和 IndexedDB 名称以兼容旧版。
- 锁定使用 🔒，高亮表示已锁定；提示文字明确锁定/解锁。眼睛、锁定、Solo 各自独立。
- 资产库和帮助保留顶部常驻入口，移除导演台内同屏重复按钮。
- 导演台的导入按钮直接导入 GLB，避免误把模型当图片/视频素材导入画布。
- 模型动作以「动作库 / 播放」为主要入口；文字描述草稿显式标记接口待接入。移除重复的「预览当前动作」按钮，动作库内提供播放。
- ⌘D 复制节点/对象，F 聚焦/适应；弹窗 Tab 焦点不会跑到背后，关闭时返回原入口。右键菜单打开时屏蔽误触删除。
- 连续编辑的保存任务按版本串行写入，旧任务完成不再误报全部已保存；失败可重试。桌面退出先等待保存。
- 机位渲染显隐处理减少重复遍历；窗口隐藏时暂停三维重绘，减少后台消耗。
- 构建工具更新至 Vite 6.4.4；依赖审计无已知漏洞。桌面使用 Electron 44.7.0。

## 保留的多个入口

节点右键和右侧属性面板都保留对应操作：前者方便就地操作，后者方便持续调参。对象列表与时间轴都可选对象；这属于不同上下文的快捷入口，不强行删去。

## 验证范围

自动测试覆盖工程结构、模型导入、连接/去重、Solo/显隐、变换/注视点、参数动画/贝塞尔、骨骼资产、颜色隔离、云端模拟请求与保存并发。真实浏览器检查锁定与 Solo 恢复、复制快捷键、弹窗键盘、两秒单机位 1280×720 视频录制及解码。未产生任何真实云端生成费用。

本次不将未完成能力包装为已完成：云端绑骨和文生动作仍未接入，模型文字动作仅检查与草稿；多导演台节点共享工程场景；视频为 WebM，不包含参考音频混音。复杂场景、长视频、Intel Mac 与跨机性能仍需进一步验证。
