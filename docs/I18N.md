# i18n 规范（Sprint 1）

英文优先：`en-US` 是源语言，`zh-CN` 是翻译包。海外默认英文，中文可切换。

## 文件

```text
src/i18n/
  index.mjs      t / setLocale / detectLocale / formatters
  en-US.json     基准文案
  zh-CN.json     中文翻译
```

## 使用

```js
import {t, setLocale, getLocale} from './src/i18n/index.mjs';

t('nav.canvas');                 // Canvas / 画布
t('task.running');               // Running / 进行中
t('welcome', {name: 'Ada'});     // {name} 插值
setLocale('zh-CN');              // 持久化到 localStorage
```

- 语言选择存 `cineweave.locale`
- 首次启动按系统语言：`zh*` → 中文，其余 → 英文
- 缺 key 时回退英文，再回退 key 本身，并记录到 `missingKeys()`
- 日期/数字用 `Intl`，不要手写格式

## Key 规范

- 小写 + 点分层：`nav.*`、`common.*`、`settings.*`、`provider.*`、`task.*`、`error.*`
- 一种语言新增 key 必须同步另一种，测试会校验 key 完全一致
- 英文文案要 natural，不要机翻；中文翻译可后置
- 服务端错误返回 `{code}`，前端用 `error.*` 翻译

## 迁移策略

- Sprint 1：框架 + 语言包 + 测试
- Sprint 3：画布/导演台/剪辑/设置/任务中心 P0 文案迁移
- 英文长文案要回归布局（按钮换行、侧栏溢出）
