# 造梦工坊交互与产品边界重构计划（2026-10-24 修订）

## 一、产品定位（本次修订的核心）

造梦工坊不是 AI 编剧，也不是聊天式创作助手。

它服务**已经有剧本/分镜的人**，帮助他们：

1. 导入已有剧本，整理镜头和资产参考
2. 用 3D 导演台搭白模预演，控制机位、走位、动作、时长
3. 把白模预演作为参考，调用**本地 ComfyUI** 或**云端 API** 生图、生视频
4. 粗剪、导出，或把生成结果送回画布继续迭代

关键词：**专业性、简单性、可预测**。

### 明确不做

- 不生成剧本、大纲、人物小传、对白
- 不做聊天式创作助手
- 不做 AI 自动拆解分镜、自动提取资产提示词
- 不改写剧本、不做“创意讨论”
- 不做开放技能市场、无限多 Agent 对话
- 不堆转场、特效、复杂字幕

### 保留

- 文本节点 / 剧本文本：作为**参考内容**导入和阅读
- 手工分镜表、镜头清单、资产设定
- 3D 导演台：白模、机位、走位、动作、关键帧、预演导出
- 本地 ComfyUI、云端图片/视频 Provider
- 任务中心、版本、引用关系、粗剪、导出
- 配置向导：ComfyUI / 云端 API 接入

## 二、现有功能越界清单

| 现有功能 | 处理 |
|---|---|
| 创作助手（Creative Assistant） | **移除主入口**；不参与核心流程 |
| 剧本创作页 / 剧本生成 | **移除**；只保留剧本导入/阅读 |
| AI 分镜与资产设计 | **移除**；分镜改为手工维护 |
| AI 局部改写 / 续写 | **移除** |
| 文字模型 / DeepSeek 设置 | 从核心设置移除；如需提示词优化，后续作为独立可选工具 |
| “文字编排人物动作” / “图文编排 3D 场景” | 降级为高级实验能力，默认不出现 |
| 提示词助手 | 可选高级功能；不阻塞主流程 |
| 示例项目 | 保留，作为“导入示例剧本+预演”的样本 |

## 三、Codex 对标研究中仍然有效的部分

研究包：`wo/work/competitive-review-20261018/`

保留这些共性结论：

- 一屏一个主任务
- 画布内容优先，选中节点才显示工具
- 工具跟随内容，低频操作进“更多”
- 生成面板统一：参考 → 参数 → 费用 → 提交 → 结果
- 结果摘要化、版本折叠、明确采用
- 状态互斥、任务可恢复、不重复扣费
- 专业能力保留但渐进披露

不采纳研究中“AI 助手/自动分镜/剧本生成”方向，因为与新定位冲突。

## 四、目标信息架构

用一条可理解的线性流程替代现有的多入口：

**剧本 → 镜头 → 资产 → 预演 → 生成 → 剪辑**

- 剧本：导入/粘贴已有剧本，只读参考；不提供生成
- 镜头：手工拆分、排序、修改时长；一张可收起的镜头表
- 资产：角色、场景、道具的参考图与设定；版本管理
- 预演：3D 导演台；白模、机位、走位、动作、导出参考视频
- 生成：图片/视频 Provider 统一面板
- 剪辑：粗剪、替换片段、导出

顶部阶段导航只切换工作重点，不重做页面，不丢画布状态。

## 五、三阶段开发计划

### 阶段 1：边界收敛与入口简化

目标：打开软件后，用户只看到“导入剧本 → 做镜头/预演 → 生成”的专业流程。

- 移除创作助手、剧本创作页、AI 分镜/资产生成入口
- 首启向导后提供三个起点：
  - 导入剧本
  - 打开示例
  - 空白项目
- 画布阶段导航：剧本 / 镜头 / 资产 / 预演 / 生成 / 剪辑
- 未选中节点时收起属性栏；选中后只显示该节点主操作
- 每个节点一个主按钮，其余进“更多”
- 空画布只给一个下一步

验收：

- 新用户不读文档能完成：导入剧本 → 建一个镜头 → 进导演台 → 导出白模参考
- 界面上找不到“生成剧本/创作助手”入口
- 1440/1024 无横向溢出，画布主区域不被属性栏挤压

### 阶段 2：统一生成面板与单镜头闭环

目标：一个镜头从参考到图片/视频，全程不离开软件。

- 统一生成面板：
  - 顶部参考缩略图 + 用途标签
  - 中部提示词
  - 底部服务商/模型/尺寸/时长（按能力显示）
  - 费用说明 + 一个提交按钮
- Provider 管理集中：ComfyUI、Seedream、Kling、Seedance，以及后续通用云端 API
- 结果卡：摘要、候选版本折叠、设为正式图/采用到镜头/送入剪辑
- 任务持久化：任务 ID、项目/镜头/资产、引用版本、状态、产物、费用
- 关闭/重启可恢复，不重复提交

验收：

- 选中一个镜头/资产，提交一次图片生成，关闭面板再打开能找到任务并采用
- 生成面板明确回答：用了什么参考、什么模型、多少钱、结果在哪

### 阶段 3：预演→视频→剪辑的专业闭环

目标：10–20 个镜头仍可管理，白模参考真正服务视频生成。

- 白模预演导出：按镜头切分、时长、机位、参考帧
- 视频生成面板支持白模视频/首尾帧/角色参考（按 Provider 真实能力）
- 分镜表、画布、导演台读同一份镜头数据
- 资产正式图/版本变更列出受影响镜头，不静默覆盖
- 剪辑接收生成版本；替换片段保留裁切、位置、音量
- 导演台简单/专业模式：默认常用机位/动作/导出，高级参数展开

验收：

- 10 个镜头项目能从剧本定位到参考、白模、生成版本、剪辑片段
- 视频生成明确使用白模参考，而不是只靠提示词

## 六、设计原则

1. **先任务，后工具**：每步只突出一个主操作
2. **选中才显示**：未选中节点不显示大属性栏
3. **生成统一**：一个面板处理图片/视频
4. **一份数据多种视图**：画布/表格/列表不重复建节点
5. **状态互斥**：排队/生成/待选/失败不混排
6. **渐进披露**：默认简单，专业能力可展开
7. **可恢复**：任务、版本、引用永远找得回
8. **不假装**：不把文本模型、自动分镜、假进度包装成核心能力
