# 超级无敌导演画布 v1.1 · 项目管理

## 使用方式

打开软件先进入本地项目库，不自动打开上次的工程。单击卡片选中，双击或点击「打开项目」进入。

- 新建：可选空白画布（一个机位）或雨后会面示例。
- 查找：搜索名称，按最近修改、最近创建或名称排序；支持缩略图与列表。
- 管理：重命名、复制、导入、导出，移入回收站后可以恢复。
- 返回：编辑器顶部「项目库」或 ⌘O，完成当前保存后返回。
- 封面：返回项目库或正常退出时，以当前机位画面更新缩略图。

## 数据兼容

沿用原应用数据目录和 IndexedDB，将 v1.0 的当前工程迁入列表，保留原记录。网页和桌面各有自己的项目库；跨环境用 JSON 导入导出。相同 ID 的文件导入为新副本，不覆盖原项目。副本有独立工程 ID，同一项目使用浏览器互斥锁避免多窗口同时编辑。

## 验证

- 自动检查 81 项通过：75 项单元/资产检查，6 项单独服务检查。
- 新增 10 项存储检查，覆盖旧工程迁移、重复初始化、项目隔离、重复导入、复制、回收站、校验失败回滚、缩略图保留和损坏数据保护。
- 浏览器实测：旧工程 6 个资产/9 个对象/3 个镜头完整；A 副本 B 新增资产后 A 不变；重命名、搜索、排序、列表、回收站恢复及 JSON 导入导出通过。
- 同一工程在第二个窗口打开时被拦截；刷新后显示项目库，编辑器不可见。无新增控制台错误。
- 测试工程已放入可恢复回收站，原项目保留。

## 本版范围

本地项目管理，不包含网络/云端项目同步、文件夹和永久清空回收站。大型项目的列表只加载元数据；打开时仍需完整加载所选项目。AI 生成能力和费用规则不变。

安装包适用于 Apple Silicon；本地签名，尚未进行 Apple Developer ID 签名和公证。升级前退出旧版，再替换 Applications 中的 App；不要同时使用旧版继续编辑。

Mac 独立测试副本验证通过：初次进入空项目库、新建并编辑、⌘O 返回保存、⌘Q 退出、重启显示项目卡片。测试使用独立端口和数据目录，未中断用户运行中的旧版。
