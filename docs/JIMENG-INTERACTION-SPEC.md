# 即梦画布交互规格（真实客户端测量）

来源：本地即梦 AI macOS 1.0.53，REA + CDP 实测
视口：1728 × 1025 CSS px，DPR 2
截图：`docs/jimeng-parity/05-local-app-canvas.png`、`08-node-attached-composer.png`

## 1. 画布壳层

| 组件 | 位置/尺寸 | 样式 |
|---|---|---|
| 页面背景 | 全屏 | `#121212` + 点阵 |
| 顶栏容器 | x12 y10 w1704 h40 | 透明，`z=30` |
| 项目标题块 | x48 y12 w287 h36 | bg rgba(13,13,13,.72)，blur 80px，圆角 8px |
| 右上控制组 | 高 36 | bg rgba(32,32,34,.8)，1px rgba(255,255,255,.04)，blur 40px，圆角 8px |
| 左侧创建栏 | x12 y318.5 w48 h444 | bg rgb(32,32,34)，圆角 12px，垂直居中 |
| 左下缩放 | x12 y973 w164 h36 | 透明容器；内部控件 36 高 |
| 右下 AI | x1596 y977 w120 h36 | bg rgba(39,39,39,.72)，blur 40px，圆角 20px |

顶栏没有实心全宽 header；标题块和右侧按钮是各自独立的半透明胶囊。

## 2. 节点

| 类型 | 尺寸 |
|---|---|
| 文本 | 243.8 × 243.8 |
| 图片 | 433.4 × 243.8 |
| 视频 | 433.4 × 243.8 |
| 音频 | 243.8 × 243.8 |

- 节点自身：无背景、无边框、圆角 8px。
- 类型标签在节点外，距节点顶部约 32px：
  - 图标 16px
  - 文字 13px
  - 颜色 rgba(255,255,255,.35)
  - 标签高度 24px，左侧与节点左对齐
- 空节点：
  - 铺满节点
  - 渐变 `canvas-empty-start → canvas-empty-end`
  - 圆角 8px
  - 中央类型 SVG 18–24px，颜色 rgba(255,255,255,.35)
- 结果图片/视频：铺满，圆角 8px。
- 选中：外描边 + 四角/两侧连接点；连接点命中区约 45×91，视觉点更小。
- 生成失败：卡内显示“视频中可能涉及版权限制，请修改后重试”+“重新生成”，文字居中，字号约 11–12px。
- 悬停/选中时右侧出现小型操作入口；生成结果图片选中后出现顶部浮动工具栏（智能改图/全景/扩图/超清/抠图/预设/多角度/打光/营销/工具/AI 助手/下载）。

## 3. 生成卡（关键）

**它不在屏幕底部，也不是居中弹窗；它贴在选中节点下方。**

空图片节点选中后实测：

- 卡片：x211 y739 **w680 h206**
- 节点：x334 y415 w433 h244，节点底 659；卡片顶 739，间距约 80px
- 圆角 20px
- 背景 rgba(34,34,34,.72)
- backdrop blur 24px
- 无边框

内部：

| 元素 | 尺寸/样式 |
|---|---|
| 上传按钮 | 48×48，bg rgba(255,255,255,.04)，圆角 8px |
| Prompt 区 | 648×66，无边框 |
| 模型按钮 | 146×32，圆角 8px |
| 画幅/分辨率按钮 | 108×32，圆角 8px |
| 生成按钮 | 32×32 圆形 |
| 费用文字 | 约 20px 高 |
| 顶部风格 chips | “相机 / 配色 / 风格”三块，高 48px |

生成按钮在 prompt 右下方，费用在按钮左侧；不是大主按钮。

## 4. 交互结论

1. 选中空节点 → 节点下方展开生成卡。
2. 选中已生成图片 → 节点上方出现编辑工具栏，不是生成卡。
3. 画布底部只放缩放/选择/抓手/AI 对话，不放生成表单。
4. 生成卡宽度与节点相关，不横跨整屏。
5. 顶栏、dock、节点都是悬浮层，画布本身全屏。

## 5. 造梦工坊当前偏差

- 生成卡固定在屏幕底部 840px：错，应该贴节点。
- 顶栏是实心 header：错，应该透明悬浮。
- 节点尺寸/标签距离未按真实值。
- 生成结果选中后缺少编辑工具栏。
- 左侧 dock 位置/尺寸未按 48×444 居中。
- 底部 AI 按钮圆角/背景/位置未按真实值。

用 1728×1025 和 1440×900 两档截图，对照本文件逐项量：

## 10. 创建与键盘基础行为

- 双击空白 → 创建菜单；点击“文本”立即创建并选中新文本节点（当前 zoom 76% 下 226×226）。
- 新文本节点初始文案：`双击编辑文本`，选中态直接进入可编辑。
- Escape：关闭菜单/参考模式弹层，并清除节点选中。
- 单击空白：清除选中。
- 节点标签在选中态仍保持外部上方。

## 15. 连接点

- 每个节点左右各一个连接 handle
- 命中区约 **42 × 85**
- 视觉点是小的圆点，不是整块
- 当前测试画布 7 节点、14 个 handle、1 条边

## 16. 快捷键待确认

按 `V` / `H` 未观察到选择工具状态变化；即梦可能使用不同快捷键或仅在特定焦点下生效。需要继续查快捷键面板/源码，不要凭习惯写死。

## 17. 框选/多选（实测）

- 从画布空白按住左键拖出选框，可选中框内节点。
- 实测框选 3 个节点后：
  - 三个节点同时出现选中态
  - 外围出现一个整体选中边框
  - 出现“编组”操作
- 注意：框选后画布会自动 fit/缩放以显示整个选区，这会影响节点屏幕尺寸；实现时要决定是否复刻自动 fit。

截图：`docs/jimeng-parity/13-marquee-select.png`

## 18. 缩放菜单与真实快捷键（实测）

点左下缩放百分比后弹出：

- 菜单 **200 × 292**
- 位置靠近左下 dock
- 菜单项 192 × 36

真实菜单和快捷键：

| 操作 | 快捷键 |
|---|---|
| 放大视图 | `⌘ +` |
| 缩小视图 | `⌘ -` |
| 适配画布 | `⇧ 1` |
| 缩放至选中项 | `⇧ 2` |
| 缩放至 50% | 无 |
| 缩放至 100% | `⌘ 1` |
| 缩放至 200% | 无 |

结论：即梦不是 V/H/F 那套传统画布快捷键；实现时必须按这组真实映射，或者明确采用自己的映射并写进快捷键面板。

## 19. 多选与自动缩放

框选 3 个节点后，画布会自动缩放显示整个选区，选中节点屏幕尺寸会变化。实现时要决定是否复刻；如果复刻，需要把 `fitView` 与“缩放至选中项 `⇧2`”统一。

## 23. Seedance 2.5 多素材真实生成（2026-10-25）

在测试画布创建视频节点：

- 模型 `seedance_2.5`
- 模式 `m2v`
- 参考 1：图片资源 `38e7f788-...`
- 参考 2：视频资源 `583bdae2-...`
- 提示词：
  `参考<Picture 1>的人物与场景，以及<Video 1>的运镜...`
- 5s / 480p / 16:9
- 报价：**90 积分**
- 结果：**成功**
- 输出资源：`9f6b68c5-e6d8-439a-93e3-3db2d1ef4bb9`

结论：

- 2.5 确实支持**图片 + 视频混合参考**。
- 参考顺序与 `<Picture n>` / `<Video n>` 编号一致。
- 音频参考尚未实测（没有现成音频资源）。
- 多素材生成成本高于单参考（本次 90 积分）。
