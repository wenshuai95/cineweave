# 造梦工坊 v1.27.0 交付验收

日期：2026-10-24
版本：1.27.0

## 一、产品边界

造梦工坊服务**已有剧本/分镜**的创作者：

- 导入剧本参考
- 手工维护镜头表
- 管理角色/场景/道具资产
- 3D 白模预演
- 本地 ComfyUI / 云端 Seedream 生图
- 视频 Provider 生成
- 粗剪、导出

明确不做：

- 不生成剧本、大纲、对白
- 不做创作助手对话
- 不做 AI 自动分镜/资产设计
- 不自动下载 H3 模型

## 二、本版变更（1.26.4 → 1.27.0）

### 阶段 D 收尾

- 节点内显示生成进度与失败原因；生成中可「停止等待」，后台任务继续
- 生成面板打开即聚焦描述；⌘/Ctrl+Enter 提交、Esc 关闭
- 失败或停止等待后重新获取报价，不复用已消费的 quoteId
- 剧本参考与镜头表 ⌘/Ctrl+Enter 保存，打开即聚焦主输入
- 3D 导演台 ≤1150px 工具栏换行，不再溢出右侧属性栏

### 生成历史增强

- 「最近生成」列出 queued / running / succeeded / failed 任务，显示 provider、描述摘要、状态与进度
- 进行中任务提供「刷新状态」；成功后提供「加入画布」；失败显示原因
- 打开面板自动刷新；有进行中任务时自动轮询并更新行状态
- 关闭面板或停止等待后进行中任务仍可找回；恢复结果不重复创建节点

### 视觉与交互（1.26.0–1.26.3 收尾）

- 右侧节点属性栏收敛为：名称 + 一个主操作 + 编辑 + 折叠「更多」
- 生成卡构图 / 配色 / 风格 chips 收进「更多」
- 图片/视频结果卡统一为预览 + 摘要 + 主次操作
- 六阶段导航、紧凑属性栏、深色 UI tokens 保持一致

## 四、已知限制

1. H3 模型未安装，只保留本地接口；缺模型时不阻塞现有生成
2. 白模参考视频包依赖本机 ffmpeg；缺失时保留原视频并标记 `normalized=false`
3. Windows 版本暂停
4. 画布页按 canvas-first 设计隐藏左右侧栏；节点操作使用浮动工具条，3D 导演台保留右侧属性栏
5. 进行中任务的找回入口在「最近生成」折叠区；关闭生成面板后不再主动轮询后台任务
6. 失败/取消历史行只展示原因，不提供自动重试，避免误重耗
7. Provider 失败文案按上游原文展示，未做完整翻译
8. 1024 为视口模拟（应用窗口最小宽度 1080）
