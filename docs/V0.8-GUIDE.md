# v0.8.1：文字 → 图片 → 3D 模型 → 导演台

## 需要开通什么

- 旧版媒体 CLI：沿用本机官方 CLI 授权，负责根据文字生成图片。图片生成先查询积分，再由用户确认提交。
- 腾讯云「混元生 3D」：新增建模服务。如果在「混元生 3D → API Key 管理」拿到一个密钥，在软件顶部「API 设置 → 腾讯云 · 混元生 3D」选择「混元生 3D API Key（单密钥）」，只填写该 API Key，然后点「应用腾讯云配置」。无需填 SecretId / SecretKey。只有使用腾讯云访问管理 CAM 的密钥对，才选择第二种鉴权方式并填两个字段。TokenHub 密钥不适用这个单密钥入口。只配置普通混元聊天模型不够。
- DeepSeek：两条图片建模流程不需要它。现有的布局与动作编排功能仍可选用兼容接口。

## 场景流程

1. 在文本节点写场景描述，点击右侧「旧版媒体 CLI 生成图片」。确认积分并提交，完成后会出现相连的图片节点。
2. 选中图片节点，点击「生成 3D 场景模型」。也可从顶部「图片 → 3D 模型」选择工程内任一图片。
3. 确认参考图、名称和最长边尺寸。场景默认最长边 8 米；默认混元版本 3.1，也可选择 3.0。确认上传并付费生成。
4. 完成后画布增加 3D 模型节点，与原图连线。卡片显示输入参考图，**不是模型渲染预览**。
5. 选中模型节点，点「加入导演台 / 查看模型」（或双击节点）。实际网格出现在导演台，可移动、旋转、缩放、打关键帧、隐藏、锁定和 Solo。画布同时连接到预演节点。

先从单体建筑、房间或局部环境试起。单张图片无法提供完整背面与被遮挡区域；本流程生成整体模型，不保证可走入的完整场景，也不自动把门、桌子、道路等拆成独立对象。需要分别调度的物件建议分别建模，进入导演台后组合。

## 角色流程

同样先用 旧版媒体 CLI 生成图片，然后在图片节点点「生成 3D 角色模型」，选择人形、动物或怪物 / 其他生物。分类用于组织资产、提示拍图方式与设置本地尺寸，均使用同一图生 3D 接口，不代表平台保证所有生物结构都能正确生成。

建议画面只包含一个完整主体，背景干净、四肢无遮挡。需要后续绑定骨骼的人形建议提前生成 A/T 姿态参考图。动物和怪物保留自然结构。3D 生成质量需实际查看。

本版接入图片建模，未接入云端绑骨或文生动作。生成模型可以整体走位；手脚关节动画需要后续绑骨、匹配骨架和动作重定向。不能把现有成人模型的动作直接套给任意动物或怪物。腾讯接口目录有独立的绑骨和文生动作服务：https://cloud.tencent.com/document/product/1804/120838

## 费用、恢复与本地保存

- 图片建模会把所选图片上传至腾讯云并可能收费。界面不显示虚构报价；以腾讯云控制台的当时计费为准。本版不查询账户余额或预估积分。
- 选择模型类型、设置导入米数在本地完成，不改变提交模型参数。提交采用 Normal 带纹理模式、PBR、目标面数 30000。
- 上传前最长边缩至最多 2048 像素并转 JPEG；宽高均至少 128 像素，极长窄图需先裁切。上传的是处理后的图；原画布图片保留。
- 生成时可以关闭弹窗继续编辑。刷新后通过「图片 → 3D 模型 → 恢复 / 查看 3D 任务」，或「API 设置 → 3D 任务」恢复。只列当前工程任务，不会把结果加到另一工程。
- 恢复仅查询 / 下载既有任务，不重新付费生成。网络导致提交结果不确定时不会自动重发，请到腾讯云核对任务，避免再次点击新生成。
- 腾讯任务与结果下载链接有效期 24 小时，请及时恢复。下载完成的 GLB 存在本机 .local/model3d/；加入画布后网格和纹理嵌入工程，可导出 JSON 和单独 GLB。
- 本地 GLB 上限 40 MB，要求内嵌资源且无需 Draco/KTX/Meshopt 解码。遇到未支持的输出地址、格式或压缩方式会提示手工处理，不会把无效数据当作成功模型。
- 多个预演节点共享工程内的导演台场景。
