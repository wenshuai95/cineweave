# 造梦工坊 UI 简化计划（v1.26）

目标：像苹果设计一样简单、优雅、易用；保留专业能力但默认收起。

## 一、设计原则

1. 一屏一个主任务
2. 一个主按钮，其余进「更多」
3. 选中才显示工具；未选中保持画布干净
4. 生成只有一个入口：大图预览 + 底部生成卡
5. 高级参数默认折叠，但可随时打开
6. 状态就近显示：节点进度、失败原因、费用
7. 统一圆角、间距、字号、边框和按钮层级
8. 不做假控件：没有真实能力的按钮不出现

## 二、目标结构

### 画布
- 空白：导入剧本 / 新建镜头 / 导入素材
- 选中节点：
  - 节点上显示主操作
  - 右侧只显示「名称 + 主操作 + 高级」
- 生成中：节点内进度条 + 停止等待
- 生成完成：结果卡 + 候选/正式图/送剪辑

### 生成面板（图片/视频共用）
- 顶部：大图/视频预览
- 中部：参考、模型、画幅 chips
- 描述：唯一主输入
- 底部：费用 + 一个主按钮
- 生成中：进度、停止等待
- 完成后：结果摘要 + 采用动作

### 编辑面板
- 图片/角色/场景：预览 + 名称 + 说明 + 生成
- 文本：编辑 + 模板 + 设为剧本
- 高级：版本、引用、镜头关联全部折叠

## 三、分阶段

### 阶段 A：节点属性栏收敛
- 右侧顶部改为主操作区：名称 + 生成/编辑
- 「内容」折叠
- 所有次级操作进「更多」
- 未选中时隐藏空属性栏

验收：选中图片节点只看到 1 个主操作和 1 个「更多」。

### 阶段 B：生成面板统一
- 图片/视频共用同一布局和文案
- 参考、模型、画幅固定 chips
- 费用和提交只出现一次
- 生成中状态与节点进度同步

验收：图片和视频面板结构一致，不出现第二套弹窗。

### 阶段 C：视觉系统
- 统一圆角、间距、字号、按钮高度
- 减少边框和嵌套标题
- 主色只用于主操作
- 深色背景层级：画布 / 卡片 / 浮层

验收：同一屏不超过 2 种按钮样式、1 个强调色。

### 阶段 D：验收
- 首启 → 新建 → 导入剧本 → 镜头表 → 生成 → 剪辑
- 1440 / 1024 宽度
- 键盘 Esc / Enter / ⌘Enter
- 无 console error
- 生成进度和失败恢复
