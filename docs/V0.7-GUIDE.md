# 镜场 v0.7

刷新 http://127.0.0.1:4173/ 使用更新。原工程无需重新创建；已有动物模型也会在刷新后重新正确加载。

## 独立显隐

左侧每个对象行新增眼睛按钮，点击隐藏，再点显示。与锁定、Solo 独立，不会因退出 Solo 而把主动隐藏的模型显示出来。人物、道具、场景模型的隐藏同时影响机位监看、截图和视频导出。机位的眼睛只隐藏编辑视图里的摄影机图标，不会删除机位或改变镜头编排。显示状态保存进工程，也可以撤销。

## 剪断连线

点击画布连线，选中的线呈金色，再点击画布左下角「✂ 剪断连线」，或按 Delete / Backspace。右键连线也可选择「剪断此连线」。只断开这一条连接，保留两端节点；⌘Z 可恢复。拖拽圆点建立连接的功能保留。

## 成人骨骼模型离线动作

成人比例男、女白模各内置六个动作：站立呼吸、原地走路、原地跑步、挥手、坐姿、双手举起。新加入的成人白模默认站立呼吸。选中模型，右侧名称下方点击「离线动作库」选择，再点「▶ 预览当前动作」。已有模型也会读取新版动作文件，无需重新下载。

动作保存在 GLB 中，离线可用、不需要 API。它们是本地制作的程序化基础预演动作，并非动捕；原网格、65 骨骼和蒙皮权重保留。动作按时间轴整段循环，位置/旋转关键帧独立控制走位。坐姿需要自行放置椅子。其他模型仍可选择原文件自带动作；任意外部骨架之间尚不能自动重定向。

## 自带人物体型

选中林舟等基础人偶，在右侧「人物体型」选择成年男性、成年女性、男孩、女孩。参考身高分别为 1.8、1.65、1.15、1.10 米，可继续用比例调整。儿童有独立头身与四肢比例，并非仅整体缩小成人。变更体型保留对象身份、名称、走位、关键帧与已有动作；工程保存后可恢复。

## 动物导入修复

问题来自克隆骨骼后，尚未更新骨骼世界变换就计算了模型尺寸。柴犬被错误测为约 416 单位而真实最长边约 4.16，最终缩至毫米级，看起来像没有导入。

现在先更新骨骼变换再计算实际顶点包围盒，并通过独立容器统一尺寸和落地。动物原生动画不会覆盖归一化变换。柴犬约高 0.65 米、哈士奇 0.8 米、马 1.8 米、奶牛 1.5 米。导入完成后自动聚焦；右侧有加载成功/失败状态，避免无反馈。新导入模型会退出模型组的 Solo，以免被独显状态遮掉。
