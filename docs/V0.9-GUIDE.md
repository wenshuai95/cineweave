# v0.9 · 节点右键菜单与模型连线

## 从文字到导演台

1. 右键文字节点 → **生成参考图片 · 旧版媒体 CLI** → 选择场景参考图或角色参考图。打开生成窗口后，检查提示词，再确认生成。
2. 右键生成的图片节点 → **建立 3D 模型 · 腾讯混元** → 选择场景、人形角色、动物或怪物。窗口会自动带入图片与用途；检查尺寸后再确认上传和付费生成。
3. 完成后得到一个 **3D 模型节点**。按住它右侧的圆点，拖到 **3D 导演台节点左侧圆点**，松开即可自动接入。
4. 双击导演台节点，选中导入模型，可以调整 XYZ、旋转、比例和位置关键帧。

没有导演台节点时，右键空白处 → 新建节点 → 3D 导演台；也可右键模型 → 连接到 3D 导演台 → 新建导演台并连接。

## 按节点类型显示操作

- 文字、场景、角色：生成场景 / 角色参考图，使用已有资产规划布局。
- 图片：生成参考图、四种 3D 建模用途、恢复建模任务、替换和下载图片。
- 模型：选择目标导演台、创建导演台并连接、在导演台查看、下载 GLB。
- 导演台：进入、导出预演、截帧、从菜单接入已有模型。
- 视频、音频：导入替换、下载。
- 所有节点：编辑、复制、断开全部连线、删除。

一级菜单支持鼠标悬停或点击展开；方向键可进入和选择二级菜单，Esc 关闭。菜单会避让屏幕右边缘和底边。

## 连线规则

**绿色模型连线会实际导入几何体。** 普通文字 / 图片连线用于参考，不会触发收费 AI，也不会把图片直接当成三维模型。

模型节点重复接入不会重复创建对象。剪断连线只移除画布关系，保留已摆放的对象、显隐、锁定和动画；重新连接会复用原对象。若确实不再需要对象，可在导演台单独删除。连线、接入和剪断均可撤销。

多个导演台节点仍是同一工程三维场景的入口，尚不支持每个导演台独立场景。生成场景模型与角色模型使用相同的接入方式；场景模型仍是一整份网格，单图不保证可进入的完整空间或自动拆分物体。

## API 与当前验证范围

菜单和连接不需要新增 API。生成图片沿用 旧版媒体 CLI，图片建模沿用腾讯混元生 3D。只有生成窗口里的确认按钮才会提交云端任务。新生成角色目前按静态模型接入；骨骼绑定与文字生成动作尚未接入。

本版以本地柴犬 GLB 验证模型连线、实际渲染、剪断与重连，未提交真实收费生成。单元测试覆盖四种模型用途、去重、工程保存恢复、保留对象状态及容量错误回滚。
