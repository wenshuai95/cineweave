# 动作库重定向（v1.23）

内置动作库分布在不同骨架上：成年角色自带 24 段动作，而通用动作库（UAL2）的 85 段挂在另一套人偶骨架上。
「扩展动作库（重定向）」把这些片段烘焙到当前角色身上，生成一个动作更多的新模型。

## 使用

1. 画布上选中一个 **3D 模型节点**（例如「女演员 · 休闲装」）。
2. 右侧属性栏 → **扩展动作库（重定向）**。
3. 选动作库：通用动作库 85 段 / 表演动作库 46 段。
4. 点「开始重定向」，本机 Blender 后台烘焙（约 15–60 秒），进度显示烘焙段数。
5. 完成后自动新建一个「角色 · 扩展动作」模型节点（`RT_` 前缀片段），拖线到导演台即可用。

原模型不会被修改；项目里的模型引用会写入本机资产库（`/api/assets/...`），不会把 6MB 塞进工程 JSON。

## 前置条件

- 本机安装 Blender 4.x / 5.x（默认 `/Applications/Blender.app`，可用 `BLENDER_PATH` 覆盖）。
- 仅支持内置资产或本机资产库里的 GLB；不接受任意本地路径。

## 实测（2026-10-19，M1 Max）

| 项目 | 结果 |
|---|---|
| 目标 | `adult-female-casual.glb`（24 段） |
| 动作库 | `female-anatomy-mannequin.glb`（85 段） |
| 骨骼映射 | 61/61（未匹配 `Body` 辅助骨） |
| 结果 | 109 段动作、6.64 MB |
| 耗时 | 烘焙 13.2 秒（含导入导出约 35–50 秒） |

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/retarget/status` | Blender 可用性与可选动作库 |
| POST | `/api/retarget/jobs` | `{targetSrc, sourceSrc, clips?, prefix?}` |
| GET | `/api/retarget/jobs/:id` | 状态、烘焙段数、结果地址 |
| POST | `/api/retarget/jobs/:id/cancel` | 取消 |
| GET | `/api/retarget/jobs/:id/file` | 结果 GLB |
| GET | `/api/retarget/jobs/:id/report` | 映射覆盖与耗时报告 |

## 已知边界

- 两套骨架 rest 姿态不同，重定向后脚底可能滑步/悬空；重定向只保证姿态语义，不保证接地。
- 不处理 IK、接触、双人互动；根位移原样保留。
- 生成的是新节点，不会自动替换场景里已有的同角色实例。
- 动作库片段没有中文语义标签，编排阶段仍需人工挑选。
