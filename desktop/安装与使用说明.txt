超级无敌导演画布 v1.2.10
适用：Apple Silicon Mac，macOS 13 或更新版本。

安装：退出旧版本，将「超级无敌导演画布.app」拖入 Applications 文件夹，替换旧 App，然后打开。
运行环境与离线资产已内置，无需安装 Node.js。更新 App 不覆盖 ~/Library/Application Support/DirectorCanvas 中的工程。重要工程建议先导出 JSON 备份。
网页与桌面有各自的项目库，通过工程 JSON 导出、导入迁移。旧工程保持兼容。

本版：素材画布操作与快捷键升级，导演台功能保持原样。
选择：V 选择工具；空白拖拽框选；Shift / ⌘ 点击加选或减选；⌘A 选择当前分类的可见节点。
移动：拖动已选节点整体移动；方向键微调 1 个画布单位，Shift＋方向键微调 10 个单位。
视图：H 抓手；按住空格临时抓手；中键拖拽平移；Shift＋滚轮横向平移；滚轮缩放。
F 或 Shift+1 适应全部；Shift+2 聚焦所选；Shift+0 回到 100%；⌘+ / ⌘- 缩放。
编组：⌘G 编组，⌘ShiftG 解组；拖动组标题整体移动，双击标题重命名。
复制：⌘C / ⌘V，⌘D 快速复制；同时保留所选节点间的内部连线和完整编组。
跨工程粘贴不复制导演台对象、镜头、动作或生成任务绑定，素材副本需要重新接入目标导演台。
包含大量媒体的数据超过剪贴板文本上限时，使用本次会话内存副本；可通过工具条粘贴，退出应用后不保留该副本。
删除：Delete / Backspace 只删除所选画布节点及相关连线，导演台对象和镜头保留。
撤销：⌘Z / ⌘ShiftZ；拖拽中按 Esc 取消；⌘S 保存。
工具条提供对齐、等距分布、小地图及可搜索的画布快捷键速查。输入框、媒体控件和弹窗内不会抢占文字编辑快捷键。

已有功能：图片、视频、音频和 GLB 外部拖拽导入；项目库；可调面板布局；离线角色、动作和定格姿势；时间轴与关键帧；预演输出连线。
预演导出可选择 H.264 / MP4（运行环境支持时），不支持的环境使用 WebM；音频参考不混入预演。
旧版媒体 CLI 生图需要本机安装并授权官方 CLI；云端建模等需要相应接口配置。API 密钥不包含在安装包中。
关闭窗口后应用仍驻留，⌘Q 保存并完全退出。

签名：本包采用本机临时签名，未经过 Apple Developer ID 签名和 Apple 公证。其他 Mac 可能提示无法验证开发者，请核对来源后按系统设置提示处理。
第三方许可保留在 App/Contents/Resources 和应用内 assets/licenses。

验证：自动化测试、生产构建、浏览器交互验收、原生桥接测试、应用签名完整性及 DMG 镜像验证。尚未完成新版安装后的整套原生界面手动验收。
