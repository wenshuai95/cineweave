造梦工坊 v1.29.0
适用：Apple Silicon Mac（arm64），macOS 13 或更新版本。

【安装】
1. 打开「造梦工坊-v1.29.0-AppleSilicon.dmg」。
2. 将「造梦工坊.app」拖入 Applications（应用程序）文件夹；已有旧版会提示替换。
3. 首次打开如提示“无法验证开发者”：在“系统设置 → 隐私与安全性”中仍要打开。签名状态可在终端用 codesign --verify --deep --strict "/Applications/造梦工坊.app" 检查。
4. 本包为本机临时签名，未做 Apple Developer ID 签名与公证；请只从可信来源获取安装包。
运行环境与离线资产已内置，无需安装 Node.js。

【数据位置与备份】
- 工程与素材保存在 ~/Library/Application Support/AIWorkstation。
- 升级或重装 App 不会删除工程；重要工程建议在“项目库 → 导出”JSON 备份。
- 网页版与桌面版各有项目库，通过工程 JSON 导入/导出迁移。

【首次配置（设置 → API 服务）】
- ComfyUI（本地，免费）：填写地址 http://127.0.0.1:8188，可点“启动 ComfyUI”或“检测”。本包不下载模型；首次使用需你本机已有 ComfyUI 与相应模型。
- Seedream（可选，云端）：填写 API Key，选择 Agent Plan 或方舟按量，再“测试模型列表”。密钥只保存在本机配置，不写入工程。
- Kling / Seedance 视频 Provider（可选）：在设置中填写各自凭证；Seedance 需要显式开启且会产生云端费用。
- Seedance 2.5（可选）：配置方舟 API Key 并显式设置 ARK_SEEDANCE_25_ENABLED=1；模型选择出现「Seedance 2.5（多素材参考）」后可用 30/10/10/50、4–30s、480p/720p/1080p。未配置时模型置灰并说明。
- H3：只提供本地接口与缺失项检测，不自动下载、不安装模型；缺模型不影响现有生成。
- 未配置云端服务时仍可使用画布、镜头表、3D 白模、本地 ComfyUI 与剪辑。

【导航与保存】
- 顶部左侧只有一个「画布 ▾ / 工作区·创作阶段」下拉：画布、3D 导演台、剪辑和六阶段都从这里进入，不再有第二套导航。
- 保存失败时状态栏会显示具体原因；点击状态栏会真正重试保存，失败后也会自动重试一次。

【推荐流程】
1. 项目库：新建项目或导入已有工程 JSON。
2. 剧本：进入“剧本”阶段，粘贴/导入已有剧本参考（只作参考，不生成剧本）。
3. 镜头：进入“镜头”阶段，手工维护镜头表（场景、画面、时长、运镜、对白），保存后供预演/生成/剪辑使用。
4. 资产：手工建立角色/场景/道具，导入或生成参考图，选择正式图。
5. 预演：在“3D 导演台”摆放机位、走位、动作与关键帧；导出 →“白模参考视频包”按镜头输出（自动规范为 24fps，需要本机 ffmpeg；缺少 ffmpeg 时保留原视频并标记 normalized=false）。
6. 生成：选中图片/视频节点时从画布底部浮出生成卡：参考 / 模型 / 画幅或分辨率 / 时长，描述为唯一主输入；⌘/Ctrl+Enter 或“查看费用 → 确认生成”。视频节点可连接多张图片、多段视频、多段音频作为参考，按连线顺序编号。
7. 生成结果：图片可设为正式图、加入资产版本、查看同源候选；视频可送入剪辑或保存素材库。
8. 剪辑：在“剪辑”阶段粗剪、替换片段、导出预演。

【生成面板与历史】
- 打开生成面板会自动刷新“最近生成”，列出排队中 / 生成中 / 已完成 / 失败任务，显示服务商、描述摘要、状态与进度。
- 进行中任务可点“刷新状态”；完成后点“加入画布”；失败会显示原因。
- 生成中可直接“停止等待”，或按 Esc / 点关闭离开面板；任务会在后台继续，回到“最近生成”刷新即可找回，不会重复创建节点。
- 失败或停止等待后会重新获取报价，不会复用已失效的报价。
- Seedance 2.5 的图片参考支持 base64；本地视频/音频参考需要可访问 URL，当前上传/URL 托管尚未打通，会明确提示而不会静默降级。

【键盘】
- ⌘/Ctrl+Enter：生成面板提交；剧本参考与镜头表保存。
- Esc：关闭弹窗/取消输入；生成面板空闲时关闭。
- ⌘S 保存；V 选择工具；H 抓手；F 适应画布；Delete/Backspace 删除所选节点。
- 详细快捷键可在画布工具栏“快捷键”中搜索。

【安全与边界】
- 服务只监听 127.0.0.1，不依赖外网；不会自动上传工程或素材。
- 不生成剧本/大纲/对白，不做 AI 自动分镜或资产设计；只服务已有剧本的预演与生成。
- 调用云端生成会按服务商计费；请在“查看费用”确认后再提交。
- 不要在截图、Issue 或工程文件中粘贴 API Key。
